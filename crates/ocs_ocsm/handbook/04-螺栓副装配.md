# 04 螺栓副装配（`OCSMJOINT`）

> 从"两块板 + 一个孔"到"整套螺栓副"：算长度、按件链放置、遮挡裁剪、一次撤销。
> **命令只做确定性执行**；"该不该加垫圈/防松件"由工况判断（见 `21-知识-紧固件选型与防松.md`）。

> **开工先分类**（`13-任务启动协议.md`）：图上**孔已给**、只补螺栓 → 从孔径/板厚反推（逆向，本页流程即可）；
> 若"孔还没定/要新设计连接" → **先向用户索要设计输入**，选型走 `21-知识-紧固件选型与防松.md`。

## 一、两种用法

| 用法 | 命令 | 适合 |
| --- | --- | --- |
| **人类**：开窗口配 | `OCSMJOINT`（**不带参数**） | 边看实时预览边改件链 |
| **AI/脚本**：一行直装 | `OCSMJOINT at x,y rot 度 [protrude 扣数] bolt=<族>:<d>[:<l>] [plate=<厚>\|gap=<厚>\|nut=<族>:<d>\|washer=<族>:<d>] …` | 已知工况、批量、可回归 |

人类流程：

```
OCSMJOINT                       → 打开「OCSM 螺栓副装配」窗口 + 进放置态
窗口里：① 选螺栓族/直径/长度(自动或手选)/露出扣数
        ② 编辑件链（板/间隙/垫圈/螺母，可增删上下移）
        ③ 常用件链模板（无防松 / 平垫 / 弹垫 / 双螺母…）
        右侧：实时预览(真实几何，含遮挡裁剪) + 数字 + 那一行推理
        点「装配到图纸」
回图纸：点一下定位基点 → 移动光标旋转 → 再点落定（可连续，Esc 结束）
```

## 二、语法（AI 直装）

```text
OCSMJOINT at x,y rot 度 [protrude 扣数] bolt=<族>:<直径>[:<长度>]
          [plate=<板厚> | gap=<间隙厚> | nut=<族>:<直径> | washer=<族>:<直径>] …

实例如下（都是可跑的）：
# 两块 10 板 + C 级螺母（无防松）
OCSMJOINT at 50,10 rot -90 bolt=hex_bolt_b_full:8 plate=10 plate=10 nut=nut_c41:8
# 平垫 + 弹垫 + 螺母（弹垫防松）
OCSMJOINT at 50,10 rot -90 bolt=hex_bolt_b_full:8 plate=10 plate=10 washer=washer_971:8 washer=washer_93:8 nut=nut_c41:8
# 双螺母防松：薄螺母在内 + 厚螺母在外
OCSMJOINT at 50,10 rot -90 bolt=hex_bolt_b_full:8 plate=10 plate=10 washer=washer_971:8 nut=nut_61721:8 nut=nut_c41:8
# 双螺母防松：两个厚螺母
OCSMJOINT at 50,10 rot -90 bolt=hex_bolt_b_full:8 plate=10 plate=10 washer=washer_971:8 nut=nut_c41:8 nut=nut_c41:8
```

要点：

- **件链必须 `bolt=` 开头**（螺栓是长度基准与轴线基准）。
- 每件可写两种形式：`<类型>=<族>:<d>`（如 `nut=nut_c41:8`）或**直接族名**形式 `<族>=<d>`（如 `hex_bolt_c=8`）。
- `protrude <扣数>`：期望露出的螺纹扣数（1 扣 = 1 个螺距），**默认 2.5**。
- `view <视图>`：覆盖默认 `main`（一般不用改）。
- `trim off` / `no-trim`：**关掉遮挡裁剪**（要"全件实画"时用）。
- `at x,y`、`rot 度`：基点（=螺栓头部支承面）× 轴线方向；`rot -90` = 杆朝下。
- HTTP 同款：`POST /api/joint`，body = `{"at":[x,y],"rot":-90,"protrude":2.5,"trim":true,"view":"main","items":[{"kind":"bolt","family":"hex_bolt_b_full","d":8},{"kind":"plate","t":10},…]}`。
- 只算不写（预览）：`POST /api/joint_plan`（返回 SVG + 报告 + 数字，**不动文档**）。

## 三、命令做的三件确定性事

1. **Σ 件高**：把件链里非螺栓件的高度加起来（板/间隙=给定厚度；垫圈/螺母=**国标表**里的厚度，
   例如 平垫 97.1 M8 = 1.6、弹垫 93 M8 = 2.1、薄螺母 6172.1 M8 `m` = 4.0、C 级 41 M8 `m` = 7.9）。
2. **长度落点**：`需 l ≥ Σ + 露出扣数 × 螺距`，在**该族表内供货长度系列**里取 ≥ 需求的**最小**值
   （"略长为宜"）。取不到就报该族最大长度并提示换族（例如 C 级 M8 装不下 → 建议 5783 全螺纹）。
   - 供货系列 = 表里列出的档（厂家实际可购）。GB/T 是推荐标准，厂家常做接近标准的增减档，
     所以**以表为准**、不按公称系列硬卡。
3. **沿轴放置**：每件基点按自己的族约定落到 `Σ` 累计位置；整链**一次事务 = 一个撤销条目**。

同时输出**一行可审计推理**（命令行日志 + 报告），例如：

```
OCSMJOINT：六角头全螺纹螺栓 全螺纹 B级 GB/T 5783-2016 M8×35｜件链 板厚 10 + 板厚 10 +
平垫圈 A级 GB/T 97.1-2002 M8(厚1.6) + 标准型弹簧垫圈 GB/T 93-2025 M8(厚2.1) +
六角螺母 C级 GB/T 41-2016 M8(m7.9) → Σ31.6｜需 l ≥ 34.725(= Σ31.6 + 露出2.5扣×1.25)
→ 取供货长度 35（实际外露 3.4mm≈2.7扣）｜基点 (50, 10) rot -90°｜共 4 件
｜遮挡裁剪 六角头全螺纹螺栓 全螺纹 B级 M8×35 被遮 20~31.6
```

## 四、遮挡裁剪（外形视图不画被挡住的线）

- 被**螺母/垫圈**包住的那段**螺栓杆**（含螺纹细实线）**不画**：直线按轴向区间减集
  （整段删 / 一头截短 / 跨区间断成两段），弧圆整体被遮才删，**中心线层不裁**（轴线通长）。
- 判据是"就地比粗细"：环形件轮廓径向尺寸 ≥ 杆**在该窗口内**的径向尺寸才算遮得住
  （M8 杆 Ø8/2=4；平垫 8、弹垫 6.2、螺母 7.5 都遮得住）。
- 裁剪在**生成几何之后、写块之前**做：被裁的件用一个带裁剪标记的块名，例如
  `OCSM_HEX_BOLT_B_FULL_M8_35_CUT20x31.6`；预览块是 `OCSMJOINT_PREV_…`。
- 关掉：命令加 `trim off`，HTTP 加 `"trim": false`。
- **边界**：件链里的 `plate=`/`gap=` 只是"厚度账"，命令不拿板的外形 → 杆在板孔里照画（剖视图本来就该画）。
  裁剪是**插入时定格**的：之后拖动螺母，螺栓不会自动重裁（要重来一次装配）。

## 五、长度速查（钢制、M 螺纹粗牙、默认露出 2.5 扣）

| 工况 | Σ | 需 l | 取供货 | 实际外露 |
| --- | --- | --- | --- | --- |
| 两板 10+10 + C 级螺母 M8 | 27.9 | 31.03 | **35**（5783 全螺纹） | 7.1 mm ≈ 5.7 扣 |
| 两板 10+10 + 平垫 + 弹垫 + C 级螺母 M8 | 31.6 | 34.73 | **35** | 3.4 mm ≈ 2.7 扣 ✓ |
| 两板 10+10 + 平垫 + 薄螺母 6172.1 + C 级螺母 M8（双螺母） | 33.5 | 36.63 | **40** | 6.5 mm ≈ 5.2 扣 |

> 规律：**要落在 2~3 扣外露，就要让件链刚好把供货档"填满"**；填不满就跳到上一档（外露偏多，仍然合法）。
> 想让外露更贴，可调 `protrude`（例如 `protrude 2` 或 `protrude 3`）再让命令重取档位。

## 七、坑

1. **件链顺序 = 从被连接件往外**（`plate plate washer nut`）。顺序错 → 长度与位置都错（命令不会猜）。
2. **不要用 `OCSMJOINT` 替代工况判断**：要不要平垫/弹垫/双螺母、螺栓等级——由你（或 skill 层）按
   材料压溃、振动、装配频次决定后写进件链。**压溃怎么算**见 `21-知识-紧固件选型与防松.md` §四，
   配套脚本 `manual/tools/crush_check.py`（例：`python3 crush_check.py M8 8.8 hex_ab mat=6061 dh=10 → 超限，加平垫后通过`）。
3. **`bolt=` 里给死长度**（`bolt=hex_bolt_b_full:8:40`）会跳过长度规则；只在"必须用现有物料"时这么做。
4. **两块板必须是"厚度账"**：命令不量你的板，只收 `plate=<厚>`；量错厚度 → 长度整体错。
5. **遮挡裁剪后块名带 `_CUT…`**：同一个副在不同件链下会生成不同块（这是有意的，几何不同）；
   想复用同一块就让件链一致。
6. **预览块 `OCSMJOINT_PREV_*` 是给光标跟随用的**：落定后它就没人引用了，可 purge。
7. **装配窗口也是「钉在图纸上」的**（URL 带 `tab=`）：装配/落件只落在开它那张图；图被关后
   旧窗口立即报错（不再空转 5 s，也不会写到别的图上）。规则见 `06-引导线标注.md` §五.7。

## 八、验证清单

- [ ] 日志里有 `OCSMJOINT：…` 报告行，Σ / 需 / 取 / 外露 与手算一致。
- [ ] `query Insert` 件数与件链一致（板不产生件）；位置 = 基点 + Σ 偏移（沿 `rot` 方向）。
- [ ] 螺母/垫圈内部**没有**螺栓杆线（除非 `trim off`）。
- [ ] 一次 `undo` 撤掉整条件链。
