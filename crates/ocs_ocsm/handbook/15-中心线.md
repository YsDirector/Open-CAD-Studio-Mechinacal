# 15 中心线（`OCSMCENTERLINE` / `ZX`）

> 轴线、对称中心线、两线中间线一律用这个命令画 —— 产出是**普通 `LINE`**（不是块、不是多段线），
> 落在 `3中心线层`（线型 `CENTER2`），可以直接修剪 / 延伸 / 拉长 / 夹点拖。
> 无尺寸标注（中心线按国标不标尺寸）。

## 一、两种用法

| 你点的东西 | 出来的东西 | 线长 |
| --- | --- | --- |
| **圆 / 圆弧** | **十字**两条线（横 + 竖），中心都在圆心 | `直径 + n×6` |
| **直线**，再点**第二根直线** | 一条线，落在**两根线的角平分线**上 | `第一根线的投影长度 + n×6` |

* `n` = **图框比例**（图纸里那张图框块的 `比例` 属性；没有图框时按 1）。拾取点所在的图框决定 n，
  和 `D`（智能标注）/`GDIM` 的"比例感知"是同一套。
* 超出量固定 **6 mm × n**（1:1 图 → 每端超出 3 mm）。
* 十字永远是**世界坐标的横 + 竖**（本插件按世界坐标作图，不跟 UCS 转）。

## 二、操作

### 1. 圆 / 圆弧 → 十字中心线

```
ZX            ← 或点功能区「中心线」
点圆/圆弧      ← 一条边就行，不需要点圆心
```
→ 立刻出现十字（**两条线一次落图、一次 Ctrl+Z 撤销**）。

### 2. 两根直线 → 角平分线中心线

```
ZX
点第一根线
点第二根线     ← 出来的是这两根线的"中间那条线"
```

**平分线挑哪一根？** 两根线其实有**两根互相垂直**的平分线，本命令取
**"线段自己围出来的那个角"** 的平分线（= 交点分别到两根线**远端**的两条射线的夹角平分线）：

| 两根线的关系 | 结果 |
| --- | --- |
| 近平行（槽、键槽、间隙两条边） | **两条线中间那条线**（正确的那根，绝不会横穿过去） |
| 成角（折线、V 形、倒角） | 该角的**内角平分线**（钝角也照样取内角，不限锐角） |
| 严格平行 | 单独走"中线"分支：方向 = 线方向，位置正好在两根线正中 |

中线/平分线的**位置**由第一根线决定：**中点 = 第一根线中点在该平分线上的投影**；
**长度** = 第一根线在平分线方向上的**投影长度 + n×6**。

> ⚠️ 两根线是"第一根线定长度/位置"的，所以**先点的哪根线就是基准**。点反了 → 撤销 (`U`) 重新点。

## 三、带选区跑（脚本 / AI 用）

命令可以直接吃**当前高亮的选择集**（`XL`/`ME` 那套，MCP 里 `op:"select"` 指定 handle）：

| 选区 | 结果 |
| --- | --- |
| 1 个圆 / 圆弧 | 十字中心线（一次落两条） |
| 2 根直线 | 角平分线中心线（**选区里第一个 = 基准线**） |
| 其它（含 1 根直线、混合） | 不改图，只提示，然后进点选模式 |

```bash
# MCP / HTTP 示例：选中一个圆再跑 ZX
mcporter call ocs.ocs_execute --args '{"request":{"op":"select","handles":["1F"]}}'
mcporter call ocs.ocs_execute --args '{"request":{"op":"run","cmd":"ZX"}}'
```

## 四、常见问题

| 现象 | 原因 / 处置 |
| --- | --- |
| 点圆没反应，提示"只能点圆/圆弧或直线" | 点到了块内图元/样条/多段线。**多段线（LwPolyline）不是直线**：先用 `X` 分解，或选 `ZX` 后点真正是 `LINE` 的边 |
| 十字超出量不对 | 图框没插 / 图框没有 `比例` 属性 → `n` 按 1 算。重新走 `TF` + `OCSMFRAMEINSERT` 插一次图框 |
| 两根线出来的方向"横穿" | 点的两根线**不平行**且成了接近 90° 的角 —— 这是内角平分线，不是错；要的是"中线"就别用两根线，改成 1 个圆或用第一根线中点对齐的平行线 |
| 线太长/太短 | 线长 = 直径（或投影长）+ n×6；要精确长度直接夹点拖（普通 `LINE`） |
| 撤销 | 十字是**一个**撤销条目（两条线一起回去） |

## 五、图层与线宽（不要动）

| 项 | 值 |
| --- | --- |
| 图层 | `3中心线层`（第 3 层，`CENTER2` 线型，紫色） |
| 颜色/线宽/线型 | **一律 ByLayer**（改图层就全变） |
| 打印 | 中心线**要打印**（与 `10引导线层` 不同，后者是不打印的标注意图层） |

> `OCSM` 没跑过的图直接 `ZX` 也行：命令会先幂等补图层/线型（`1轮廓实线层` … `10引导线层`）。
