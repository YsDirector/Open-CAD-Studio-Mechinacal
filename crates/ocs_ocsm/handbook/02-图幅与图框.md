# 02 图幅与图框

> 建图幅、换图框、按比例出图。

## 一、两步流程

```
第 1 步：TF            （= OCSMFRAMEINIT）→ 打开「图框选择窗口」
第 2 步：OCSMFRAMEINSERT  → 选比例后，在图纸里点插入点落图框
```

## 一、两种用法

### A. 人侧：两步（选择窗口）

```
第 1 步：TF            （= OCSMFRAMEINIT）→ 打开「图框选择窗口」
第 2 步：OCSMFRAMEINSERT  → 选比例后，在图纸里点插入点落图框
```

### B. AI/自动化侧：一行直插（**不开选择窗口**）

```
TF <名称> [比例] [at x,y] [rot 度]      （OCSMFRAMEINSERT 同语法）
```

| 写法 | 效果 |
| --- | --- |
| `TF a3_landscape 1:2 at 0,0` | **全自动**：直接插一张 1:2 的 `a3_landscape`，基点 (0,0) |
| `TF a3_landscape 1:2` | 定好图框+比例 → 进**光标跟随**放置（点一下落定） |
| `TF a3_landscape` | 图框 + 1:1 + 光标跟随 |
| `TF 1:2 at 0,0` | **名称可省**（`frame/` 里只有唯一图框时） |
| `TF a3_landscape 1:2 at 0,0 rot 90` | 顺带旋转 90° |

* **名称**：`frame/` 里的 dwg 文件名（可省 `.dwg`、大小写不敏感，也可只写其中一段如 `landscape`）。
  精确名优先；只写一段而匹配到多个 → 报错并列出现有图框。
* **比例**：`1:2`、`1：2`（全角冒号）、`1/2`、或光写 `2`（= 缩小 2 倍）；放大写 `2:1` 或 `0.5`。
  规则同选择窗口：**两个正整数且其一为 1**。
* **坐标**：`at x,y`（`at` 可省，直接写 `x,y`；也收 `x,y,z`）。
* 报错都带用法提示：
  ```
  TF：比例必须是两个正整数且其一为 1（例 1:2 / 2:1 / 1:1）。
  TF：没有叫「a2」的图框。现有：a3_landscape / a4_portrait。
  TF：认不出的参数「乱写」。用法：TF <名称> [比例] [at x,y] [rot 度]（不带参数 = 打开选择窗口）
  ```
* 自动化里推荐**先 `cancel` 再发命令**（避免交互态残留）：

```jsonc
{ "op": "run", "request_id": "f1", "document_id": 1, "revision": 3,
  "cmd": "TF a3_landscape 1:2 at 0,0" }
```

### 第 1 步 `TF`（人侧）：选图框

- 从**插件目录**的 `frame/` 里列出所有 `*.dwg`（按文件名排序），窗口里点选即可。
  - 实际路径：`~/.config/OpenCADStudio/plugins/opencad.ocsm/frame/`
  - 当前已有：`a3_landscape.dwg`（A3 横式，含 **185×40 标题栏** + 左侧竖向附加栏）等，以目录实际内容为准。
- **图框 DWG 是用户自备数据，不在插件仓库里**（仓库 `crates/ocs_ocsm/` 下没有 `frame/`）：
  - 样例图框在维护机上位于 `~/桌面/OCSM/frame/`，装机前用 `tools/frame_clean.py --install` 清洗
    （去旧环境残留图层/字典 + 修图层颜色）后写进插件目录的 `frame/`；
  - 图框里的文字样式 `OCSM_GB` 与插件 `text_style_defs()` **同口径**（用户 2026-09-28 定案：
    以插件为准）：group 3 = TTF 名（`Zhuque Fangsong`，不是 SHX 占位的 `Unicode`）、宽比 0.7、
    `height = 3.5`（模板原来写 0.0 = 不定高）、`annotative = 1`。`tools/frame_clean.py`
    按这套参数产出，并自检查图框 DWG；其中 `annotative` 走 XDATA `AcadAnnotative`，
    LibreDWG 写 DWG 时会丢，插框时由插件 `ensure_text_styles()` 兜底对齐。
  - 新机器部署：把图框 DWG 放进上面的 `frame/`，或部署时给 `tools/deploy_plugin.sh` 传
    `OCSM_FRAME_SRC=<放图框的目录>`（同名不覆盖已装图框）；
  - 部署脚本自检里 `frame/` 为空**默认只警告 + `rc 0`**（图框是用户自备数据，脚本不生成，也不该
    拦住新用户）——因为空目录下 `TF` 只会报「找不到图框文件夹」；要把它当硬门禁（发布/CI）
    就显式设 `OCSM_REQUIRE_FRAME=1`（此时才非零退出）。
- 目录不存在/为空时报：`OCSMFRAMEINIT: 找不到图框文件夹 …。请在插件目录的 frame/ 中放入 DWG。`
- 这一步只是**登记选择**，还没往图纸里放东西 → 接着跑 `OCSMFRAMEINSERT`。

### 第 2 步 `OCSMFRAMEINSERT`：按比例插入

- 参数：**比例两个正整数，且其一必须为 1**（`1:1`、`1:2`、`2:1`…）。非法比例报
  `OCSMFRAMEINSERT: 非法的比例（必须为两个正整数且其一为 1）。`
- 没先跑 `TF` 报：`OCSMFRAMEINSERT: 没有待处理的图框选择。请先运行 TF。`
- 插件会：
  1. 计算缩放系数 `scale = scale_v2 / scale_v1`；
  2. **比例 ≠ 1 时自动创建对应标注样式**（如 `OCSM_GB_x2`）——标注尺寸随之自动缩放到图框比例；
  3. 导入图框块（含 ATTDEF 标题栏属性）；
  4. 进**光标跟随**交互：移动鼠标带图框预览 → **点一下落定**。
- 落定后标题栏属性（图名/图号/材料/比例/重量等）可直接双击 ATTDEF 编辑，或用宿主属性编辑。

## 二、比例与标注的关系（关键概念）

| 概念 | 在哪 | 说明 |
| --- | --- | --- |
| **图形比例** | 图框缩放 + `OCSM_GB_xN` 标注样式 | 几何仍 1:1 画；**不要**把图形缩到图框里 |
| **标注文字高度** | 标注样式 `OCSM_GB_xN` 的尺寸文字/箭头 | 比例放大图框时，标注自动按 N 倍放大 → 打印后字高仍是 5 |
| 标题栏"比例"格 | 图框 ATTDEF | 手填/改，如 `1:2` |

> 出图时按图框实际尺寸（A3 = 420×297）打印；因为几何 1:1，图框放大了 N 倍就是把"图纸"放大 N 倍，
> 所以标注样式也跟着放大 N 倍。

## 三、AI 侧配方

```jsonc
// 1) 打开图框选择窗口（人类点选；AI 驱动时这一步要人配合）
{ "op": "run", "request_id": "f1", "document_id": 1, "revision": 3, "cmd": "TF" }
// —— 人在窗口里选好图框、填比例、点"确定" ——
// 2) 插入（进光标跟随；AI 无法点鼠标 → 需要人类点，或由宿主 run 带点坐标）
{ "op": "run", "request_id": "f2", "document_id": 1, "revision": 4, "cmd": "OCSMFRAMEINSERT" }
// 3) 核对：图框块 + 标题栏 ATTDEF
{ "op": "read", "op": "query", "parameters": { "type": "Insert" } }
```

> AI 驱动时若无法点击：把图框当"人类环节"交给用户（或后续用无头模式导入图框块并自己缩放到目标尺寸）。

## 四、坑

1. **`TF` 后忘了 `OCSMFRAMEINSERT`**：只有登记，没有实体。
2. **比例写反**：`1:2` = 图形放大 2 倍放图框（缩小比例出图）；`2:1` = 图形缩小一半。按国标意图选。
3. **图框自带的图层/样式**：导入的图框块会带它自己的图层（如"图框线"），这是**正常**的——
   OCSM 的 10 层管的是零件几何，不必把图框搬到 `1轮廓实线层`。
4. **明细表位置依赖图框几何**：BOM 的右边界/宽度/底边是从图框量出来的（内框右边、标题栏宽、标题栏上沿），
   换图框后明细表位置要重新对（见 `10-明细表BOM.md`）。

## 五、验证清单

- [ ] `frame/` 里有你要的图幅 dwg（文件名 = 窗口里的标签）。
- [ ] 插入后 `query Insert` 能看到图框块；标题栏 ATTDEF 能编辑。
- [ ] 比例 ≠ 1 时，样式里出现 `OCSM_GB_xN`；新标注用的是它。
