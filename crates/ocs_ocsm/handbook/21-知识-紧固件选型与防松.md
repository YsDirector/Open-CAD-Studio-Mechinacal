# 21 知识：紧固件选型与防松

> 这一篇是"命令不替你判断"的那部分：**选螺栓等级 / 长度 / 要不要加平垫、弹垫、双螺母**。
> 命令侧只按你给的件链执行（见 `04-螺栓副装配.md`）。
> 本页的压溃校核**是可算的**：配套脚本 `tools/crush_check.py`（本目录下），所有表都由它生成。

## 〇、设计顺序（**先看这个**：自上而下，别倒过来）

**两个入口**（先判断）：图上有**已给的孔**、只补螺栓 → **逆向**（A 类，从孔径/板厚反推规格，见 `13-任务启动协议.md` §一）；
否则 → **从零设计**（B 类）：**第一步向用户索要设计输入**（载荷/环境/材料/约束/交付，见 `13` §二），再逐层往下算。

螺纹连接的真实设计链是**从工况往图纸走**的，图纸（本插件画的螺栓副）只是最后一步的落地：

```
① 工况载荷          齿轮箱：径向力/轴向力/倾覆力矩；油缸/压力容器：密封比压 → 会不会漏
                    ↓ 得出"需要的最小夹紧力/预紧力 F_req"
② 螺栓规格与等级     数量 n × 尺寸 M × 等级 → 单颗预紧力 F_M（强度：σ = F/A_s ≤ ~0.9 R_p0.2）
                    ↓
③ 被连接件承压校核    p = F_M / A_p ≤ p_G（**本页 §四**）
                    ↓ 这一步常常决定"要不要加平垫/法兰件、换材料、增孔数"
④ 拧紧力矩与方法     允许的 F = min(F_螺栓, F_基体) → T ≈ K·F·d（**§五**），再定扭矩法/转角法/液压拉伸
                    ↓
⑤ 材料与热处理       螺栓等级 ↔ 热处理/表面处理；被连接件热处理避免压溃与变形（见 23-知识）
                    ↓
⑥ 画图（OCSM 命令）   XY 视图里落件链：`OCSMJOINT`（见 04-螺栓副装配.md）
```

**两条经验（用户 2026-09-15 校正的口径）**：

1. **先有螺栓，再定孔**——不是先给孔再配螺栓。孔（通孔直径）由**螺栓规格 + 装配精度 + 加工方式**决定，
   要落到**标准钻头规格**与钻孔位置度公差上（见 §4.11）。
2. **螺栓强度通常高于基体强度 → 实际拧紧力矩常由基体（被连接件）控制**：
   不是"螺栓能承受多大力就拧多大力"，而是
   `允许预紧力 F = min(螺栓按等级的 F_M, 基体按 p_G 的允许值)`，
   软材料上这个上限往往**远低于**螺栓的设计预紧力（§五的反算模式会直接告诉你谁在控制）。

## 一、螺纹连接的三件事（先想清楚再画）

1. **强度**：螺栓等级 × 预紧力 ≥ 工作载荷（受剪还要算剪切/挤压）。
2. **接触面压溃**：螺栓头/螺母支承面压在被连接件上 —— 材料软（铝/塑料/薄板）会压溃、塌陷、螺栓陷入
   → **加平垫圈**（甚至法兰螺栓/加大支承面）或降预紧。判据见 §四（**本节可算**）。
3. **防松**：振动/冲击/温度变化下预紧力会衰减 → 选一种防松方式（§二）。

## 二、防松方式（OCSM 里怎么画）

| 方式 | 原理 | OCSM 件链 | 说明 |
| --- | --- | --- | --- |
| **弹簧垫圈**（GB/T 93） | 弹垫涨开刃口咬住支承面 + 弹性补偿 | `washer=washer_971:8 washer=washer_93:8 nut=nut_c41:8` | 最常用；**平垫在内、弹垫在外**（贴螺母侧） |
| **双螺母**（对顶） | 两螺母对顶，旋合螺纹受附加压力 → 摩擦力锁紧 | `nut=nut_61721:8 nut=nut_c41:8`（薄内厚外）或 `nut=nut_c41:8 nut=nut_c41:8`（两个厚螺母） | 可靠、可拆；占轴向空间（长度要重算） |
| **头部带孔螺栓 + 开口销/铁丝** | 机械锁死（不靠摩擦） | `bolt=hex_bolt_hole_a:8 …`（GB/T 32.1） | 强振动/安全关键；**开口销/铁丝库中暂无，需另行绘制** |
| 尼龙/全金属锁紧螺母 | 非金属或压点产生摩擦 | 库中暂无 → 用现有族替代或人工绘制 | 常用且可拆 |
| 螺纹锁固胶 | 化学锁固 | 不体现在图形上（写技术要求） | 小件/薄壁件常用 |
| 止动垫圈 | 机械止动 | ✅ 库里有：`lock_washer_858`（配圆螺母 `round_nut_812`）；画法：`OCSMPART lock_washer_858 <d> <s>` | 与圆螺母配用 |
| 开槽螺母 + 开口销 | 机械止动 | ❌ 库中暂无（待补族：开槽螺母 GB/T 6178 系列、开口销 GB/T 91） | 与带孔螺栓配用 |

**选法经验**：一般设备 → 弹垫（或锁紧螺母）；明显振动/冲击 → 双螺母或锁紧螺母 + 平垫；
安全关键不允许松 → 带孔螺栓 + 开口销；铝/薄板/塑料 → **平垫几乎必须**，同时降预紧力矩。

## 三、长度规则（OCSM 的算法，你要给对件链）

```
需 l ≥ Σ件高 + 露出扣数 × 螺距      （1 扣 = 1 个螺距；默认露出 2.5 扣）
取该族**表内供货长度系列**中 ≥ 需求的最小值（"略长为宜"）
```

- 螺母端面外要有 **2~3 扣**螺纹；露出过长（>5 扣）不美观也不经济。
- 露出的必须是**螺纹**：全螺纹（GB/T 5783）最省心；部分螺纹（5780/5782）要核 `b`（螺纹长）够不够——
  螺纹段没覆盖螺母 = **拧不上**（换全螺纹族，或加长到覆盖）。
- 实测档位（M8 粗牙、钢）见 `04-螺栓副装配.md` 的"长度速查"；**供货系列以表内为准**（例：C 级 M8 有 35）。

## 四、压溃（承压面压应力）校核 —— 可算

### 4.1 判据

```
p = F_M / A_p  ≤  p_G
```

| 符号 | 含义 | 取值 |
| --- | --- | --- |
| `F_M` | 装配预紧力（N） | 见 §4.3 表 A 的 `F_M` 列（= 出处表的 p × A_p，按 90% R_p0.2、μ_G=0.12） |
| `A_p` | 支承面承压面积（mm²） | 见 §4.2：按头型/有无垫圈算，**不是** 螺栓公称面积 |
| `p_G` | 被连接件材料的**许用表面压力**（N/mm²） | 见 §4.6 表 C（VDI 2230 表值） |

出处表值的前提（超出要修正，见 §4.8）：**室温、通孔无倒角、被连接件外径足够大**。

### 4.2 三种承压面（A_p 怎么算）

| 情形 | A_p | 说明 |
| --- | --- | --- |
| **六角头 A/B 级**（GB/T 5782/5783）、**1 型/薄螺母**（GB/T 6170/6172.1） | `π/4 (dw² − dh²)` | 有**垫圈面** dw（表内 `dw` / §4.3 表 A） |
| **C 级头**（GB/T 5780）、**C 级螺母**（GB/T 41） | `(√3/2)·s² − π/4·dh²` | **无垫圈面** → 六角全端面承压（面积最大） |
| **内六角圆柱头**（GB/T 70.1 / ISO 4762） | `π/4 (dw² − dh²)` | dw 见 §4.5 表 B |
| **加了平垫圈**（GB/T 97.1） | `π/4 (d2² − dh²)` | d2 = 垫圈外径；**压力降到 1/3 左右**（§4.7 表 D） |

`dw`、`s`、`d2` 都能从**插件零件库**取（`GET /api/parts`，或本仓库 `crates/ocs_ocsm/src/tables/*.json`）——
手册的表值就是从这里 + 出处资料对齐的。

### 4.8 修正与前提（别忽略）

| 因素 | 影响 | 处理 |
| --- | --- | --- |
| **孔口倒角** | 许用值可 **+20%~25%**（支承效应） | 钢件可倒角；计算取 +20% |
| **机动（电动/气动）拧紧** | 许用值可能 **−25%**（预紧力散差大） | 乘 0.75，或改用扭矩扳手/液压拉伸 |
| **通孔选粗** | `dh` 变大 → `A_p` 变小 → **压力升高**（M8：孔 Ø9 → 442；孔 Ø10 → 686） | 按 ISO 273 / GB/T 5277 选**较精**系列 |
| **薄壁/外径不足** | p_G 表值失效（材料外圈撑不住） | 加大凸台/加垫/降预紧 |
| 温度 | 高温下材料软化、预紧力松弛 | 按高温许用值折减（本表未含） |
| 表面粗糙度 / 垂直度 | 影响接触面积与预紧稳定性 | 见下表 |

### 4.9 垫圈硬度等级必须与螺栓等级匹配（ISO 887）

| 螺栓等级 | ≤6.8 | 8.8 | 9.8 | 10.9 | 12.9 |
| --- | --- | --- | --- | --- | --- |
| 100 HV 垫圈 | ✅ | ❌ | ❌ | ❌ | ❌ |
| 200 HV 垫圈 | ✅ | ✅ | ❌ | ❌ | ❌ |
| 300 HV 垫圈 | ✅ | ✅ | ✅ | ✅ | ❌ |

- **8.8 级不能用 100 HV 的软垫圈**（垫圈会被压成喇叭口、预紧力立刻衰减）；
  **10.9 要 300 HV**；**12.9 干脆不能用普通平垫**（要专门硬化垫圈）。
- 我们的库：`washer_971`（GB/T 97.1）属 **200 HV 类**（对应 ISO 7089），
  **8.8 级可用 ✓**；10.9 及以上要选 300 HV 级垫圈。GB/T 95（C 级，100 HV 类）不适配 8.8。
  （硬度等级的标准对应关系请按你们供应商数据复核一次。）

```bash
# ② 铝件：M8 8.8、6061-T6、粗装配孔 Ø10 → 超限 1.9 倍 ✗，脚本给加平垫方案
python3 crush_check.py M8 8.8 hex_ab mat=6061 dh=10

# ③ 加大预紧：M10 10.9 内六角头、6061-T6 → 超限；加平垫 Ø20 后 198 ✓
python3 crush_check.py M10 10.9 socket mat=AlMgSi dh=11
```

**结论（重要）**：
- **钢件（Q235）上 8.8 级只在 M6–M10 才"刚好"够**：M6 364、M8 442、M10 405（≤490 ✓）；
  **M12 起就超限**（M12 580、M16 515、M20 532、M24 528、M30 520 > 490 ✗）——
  原因是大规格的通孔（ISO 273 中等）把垫圈面吃掉太多。所以大规格螺栓在软钢上也要**加平垫或孔口倒角**。
  钢件到底加不加平垫：M6–M10 主要看**防松与保护承压面**，M12 以上先按压溃算一遍。
- **铝/塑料/薄板上，8.8 级螺栓基本一定超限** → **必须加平垫**（M8：442 → 135 ✓），
  或用法兰螺栓/加大支承面/降预紧力矩。
- **孔径越大压力越高**（M8：Ø9 → 442；Ø10 → 686）→ 通孔按 §4.11 定：**先螺栓、后孔**，
  孔尽量走中等/精系列，别为了好装把孔开大。
- **螺栓等级越高越"压得狠"**：10.9 比 8.8 高 47%，12.9 高 72% → 软材料上换高等级反而更危险。
- **要力矩而不是要"通过/不通过"**：用 §五 的反算模式（`--allow`）拿 `F_allow` 与 `T_max`，
  它会告诉你力矩上限是**螺栓**给的还是**基体**给的（软材料上基本都是基体）。
- 想快速判断：查 §4.3 的 `p(等级)` 值，和 §4.6 里被连接件材料的 `p_G` 比大小即可（不用手算）。

### 4.11 孔径（通孔）怎么定：**螺栓 → 孔**

孔径是**设计变量**，不是"图上先有孔"；它同时影响三件事：装配可行性、位置度要求、**承压面积（压溃）**。

1. **目标孔径**：按装配精度取 ISO 273 / GB/T 5277 系列（精 / 中等 / 粗）：

   | 螺纹 | 精装配 | **中等装配** | 粗装配 |
   | --- | --- | --- | --- |
   | M8 | 8.4 | **9** | 10 |
   | M10 | 10.5 | **11** | 12 |
   | M12 | 13 | **13.5** | 14 |
   | M16 | 17 | **17.5** | 18 |

   （M4 4.3/4.5/5、M5 5.3/5.5/6、M6 6.4/6.6/7 —— 中等列为来源表值 ✓，精/粗列 ±0.5~1 按系列；
   大规格另按你们手册的 GB/T 5277 表核。）
2. **落到钻头/加工规格**：钻出来的孔径有制造偏差、钻头也不是任意直径 →
   **实际孔径按"目标孔径向上取到可用的标准钻头/加工尺寸"**，并核钻孔的位置度公差（两板孔错位会进一步减小有效承压面）。
3. **拿实际（偏大）孔径复算压溃**：`dh` 越大 → `A_p` 越小 → `p` 越高。
   例：M8 8.8，孔 Ø9 → 442；孔 Ø10 → **686**（§4.3 表 A / §4.8）。
4. **权衡**：孔大一点 → 装配容易、位置度要求低（省成本）；代价是承压变差。
   所以**软材料上宁愿孔小一点 + 加平垫**，而不是"孔开大点好装"。
5. 精装配孔（如 M12 精 13）能明显改善承压（M12 8.8：中等孔 580 → 精孔 508），
   但装配难度上升 —— 由装配工艺与批量决定。

> 结论口径：**先按强度/工况定螺栓（规格、等级、数量），再由装配工艺定孔径，最后用实际孔径回算压溃**；
> 反过来"先有 Ø10 的孔再找螺栓"只适合改修/测绘场景（那时孔径是已定条件，就只能加平垫或降等级）。

## 五、拧紧力矩与"谁在控制"

### 5.1 允许预紧力：取"螺栓"与"基体"的小者

```
F_allow = min( F_M(螺栓，按等级/规格) , p_G × A_p(基体，按承压面) )
T ≈ K · F_allow · d          （K 见下表；细算按 VDI 2230 的 μ_G/μ_K 分解）
```

| 摩擦/润滑状态 | K | 说明 |
| --- | --- | --- |
| 干态、无润滑（钢/镀锌） | **0.20** | 默认；散差最大 |
| 镀锌（略滑） | 0.18 | |
| 轻油润滑 | 0.15 | |
| MoS₂ 润滑 | 0.14 | |
| 不锈钢防咬膏/固体润滑 | 0.12 | |

**反算工具（推荐）**：`tools/crush_check.py --allow`（它同时给出允许 F、T 上限和控制方）

```bash
python3 crush_check.py M8 8.8 --allow mat=6061 dh=10          # 铝件：基体控制 → F 9.8 kN、T ≈ 15.6 N·m
python3 crush_check.py M8 8.8 --allow mat=Q235 dh=9           # 钢件：螺栓控制 → F 18.6 kN、T ≈ 29.8 N·m
python3 crush_check.py M8 8.8 --allow mat=6061 dh=10 washer=97.1   # 加平垫后回到"螺栓控制"（T ≈ 29.8）
python3 crush_check.py M12 8.8 --allow mat=Q235 dh=13         # M12 中等孔：基体控制（差 4%）
```

退出码：`0` = 螺栓控制（基体够用）；`2` = **基体控制**（力矩上限不由螺栓强度决定）。

### 5.2 需要多大预紧力？——由上层工况决定（**知识骨架，逐步补**）

| 场合 | 上层条件 | 需要的预紧力（骨架） |
| --- | --- | --- |
| **齿轮箱/一般机械** | 径向力、轴向力、倾覆力矩、转矩反力 | 防滑移：`F_req ≥ F_横向 / (μ · n · i)`（i=摩擦面数）；防分离：`F_req ≥ F_轴向 / n + 密封/刚性余量` |
| **油缸/压力容器（密封）** | 内压 p、密封垫/О 形圈需要的**密封比压** q | `F_req ≥ q · A_密封面 / n`，且工作时仍要保住比压（内压会"顶开"法兰 → 要算载荷系数） |
| 承受交变载荷 | 疲劳 | 预紧力要避免螺栓应力幅过大（VDI 2230 的 R 系列） |
| 定位/防松为主 | 剪切销/键分担 | 预紧力可按工艺给定，重点在防松 |

> 这几行是**待细算的骨架**：齿轮箱与油缸的完整算法（载荷分配、法兰刚度、密封比压、温度）后续单独成篇，
> 落地时与本页 §五.1 衔接：`F_req → 选 n、M、等级 → 核 p_G → 定 T`。

### 5.3 拧紧方法决定"实际能到多少"

| 方法 | 实际预紧力散差 | 说明 |
| --- | --- | --- |
| 扭矩法（普通扳手/冲击） | ±30% 以上 | 摩擦散差大；只能用到设计值的 60~70% |
| 扭矩法（校准扭矩扳手 + 润滑控制） | ±15~25% | 常规生产 |
| 转角法（屈服点控制） | ±10% 左右 | 先拧到贴紧，再转固定角度 |
| 液压拉伸 / 加热伸长 | ±5~10% | 大螺栓、关键连接 |

所以**力矩表上的值不是"必须拧到"的绝对值**，而是"按方法折算后的目标值"：散差大的场合要么留更大余量、
要么提高方法等级（这也是"机动拧紧 p_G 要 −25%"的来源，见 §4.8）。

## 六、等级与材料

| 等级 | R_p0.2 min (MPa) | Rm min (MPa) | 常用场合 | 备注 |
| --- | --- | --- | --- | --- |
| 4.8 | 340 | 400 | 一般钣金/轻载 | 低碳钢 |
| 8.8 | **640** | 800 | **机械通用（默认首选）** | 调质中碳钢/合金钢 |
| 10.9 | **940** | 1000 | 重载/关键 | 易氢脆（须去氢处理） |
| 12.9 | **1100** | 1200 | 极高强度 | 脆性大、慎用；不能用普通平垫 |

- 螺母等级配对：8.8 配 8 级螺母；10.9 配 10 级（"螺栓等级 ≥ 螺母等级"）。
- 不锈钢：A2-70/A4-70 常见；不锈钢螺栓强度低于同尺寸 8.8，且**易咬死**（涂防咬膏）。
- 拧紧力矩粗估：`T ≈ K · F_M · d`，干态钢 K≈0.2 → M8 8.8：`0.2 × 18608 × 8 ≈ 29.8 N·m`。
  （更细的 K 要按润滑/镀层取，见 VDI 2230；**力矩扳手精度**决定预紧力散差。）

## 七、经验数据

- 通孔：ISO 273 / GB/T 5277 —— 中等装配 M8 → **Ø9**、M10 → Ø11、M12 → Ø13.5、M16 → Ø17.5
  （粗装配各再大一号：M8 → Ø10、M10 → Ø12、M12 → Ø14、M16 → Ø18）。
- 承压面直径：M8 A/B 级头 `dw = 11.6`；C 级头无垫圈面（六角全端面 s=13）；平垫 97.1 Ø8 外径 `d2 = 16`。
- 铝合金（6061-T6，Rm≈290、p_G=360）上 M8 8.8 会超限 1.9 倍 → **必须加平垫**（→135 ✓）。
- 铸铁（HT250，p_G=850）比钢还"抗压"（铸铁局部承压容许高）→ 铸铁件上通常不用为压溃加垫圈。
