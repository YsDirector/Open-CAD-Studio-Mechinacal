# 23 知识：材料与热处理（骨架）

> 选材写进标题栏与技术要求。本篇按"遇到再补"长。

## 一、常用材料速查

| 材料 | 牌号示例 | 强度/特点 | 典型用途 |
| --- | --- | --- | --- |
| 低碳钢 | Q235、20 | 便宜、易焊、塑性好 | 焊接机架、支架、垫板 |
| 中碳钢 | 45 | 调质后综合力学性能好 | 轴、齿轮、连接件 |
| 合金结构钢 | 40Cr、20CrMnTi、42CrMo | 淬透性好、强度高 | 齿轮、轴、高强度件 |
| 不锈钢 | 304、316、2Cr13、3Cr13 | 防腐/耐热/耐磨 | 食品/化工设备、外观件 |
| 铸件 | HT200（灰铸铁）、QT450（球铁）、ZL104（铝） | 铸造形状复杂、减振 | 箱体、壳体、带轮 |
| 铝 | 6061-T6、7075 | 轻、易加工（7075 难焊） | 轻量化结构、航空件 |
| 铜合金 | H62（黄铜）、QSn6.5-0.1（锡青铜） | 耐磨、导电 | 轴承、蜗轮、导电件 |
| 工程塑料 | POM、PA66、PTFE、PEEK | 自润滑、耐蚀、轻 | 齿轮、衬套、密封 |

## 二、热处理速查

| 工艺 | 作用 | 典型后硬度 |
| --- | --- | --- |
| 退火 | 消除应力、软化、便于加工 | ≤ 200 HBW |
| 正火 | 细化晶粒、均匀组织 | 150–250 HBW |
| 调质（淬火+高温回火） | 综合力学性能（轴类首选） | 220–320 HBW |
| 淬火 + 低温回火 | 高硬度耐磨 | 45–60 HRC |
| 渗碳淬火 | 表硬心韧（齿轮） | 表面 58–62 HRC |
| 氮化 | 表面极高硬度、变形小 | 表面 ~1000 HV |
| 去应力（时效） | 稳定尺寸（精密件） | — |

## 三、表面处理速查

| 工艺 | 效果 | 备注 |
| --- | --- | --- |
| 发黑（氧化） | 防锈、外观 | 钢件常规，膜薄 |
| 镀锌（蓝白/彩锌） | 防锈 | 标准件最常见 |
| 镀铬（硬铬/装饰铬） | 耐磨/外观 | 尺寸会变化，标注要注明"镀后尺寸" |
| 阳极氧化 | 铝件防腐/外观 | 可染色 |
| 喷砂 / 喷塑 / 喷漆 | 外观、防腐 | RAL 色号写进技术要求 |

## 四、写进图纸的习惯

- 标题栏"材料"格写牌号（`45`、`6061-T6`、`HT200`），热处理/表面处理写进**技术要求**：
  ```
  技术要求
  1. 材料 45；调质 220–250 HBW。
  2. 未注圆角 R2，未注倒角 C1。
  3. 未注尺寸公差按 GB/T 1804-m。
  4. 未注表面粗糙度 Ra 6.3。
  5. 表面处理：发黑（GB/T 15519）。
  ```
- 未注公差/粗糙度的"默认值"必须在图纸上声明，别让加工方猜。
