# 05 智能标注 `D`（`OCSMPOWERDIM`）

> 最快的一条尺寸：拾取两个点就出标注。适合线性/对齐/半径/直径的日常标注。

## 一、用法

```
命令：D        （= OCSMPOWERDIM）
输出：OCSMPOWERDIM: 拾取点模式（选端点/圆心/交点），Enter 切换线段点选；Esc 取消。
```

交互：

1. **拾取点模式**（默认）：鼠标靠近**端点 / 圆心 / 交点**会吸附，点两下 → 出标注。
2. **`Enter`**：在"拾取点模式"与"**线段点选**"之间切换（线段点选 = 直接点整条线，自动取两端点）。
3. `Esc` **取消**（MCP 侧 `op:"cancel"`）。

命令做的前置动作：确保 `7标注层` 存在、文字样式 `OCSM_GB`、标注样式 `OCSM_GB` 就绪
（样式表补齐也是文档改动，命令先声明撤销点 `OCSM 智能标注`），然后标注落在 `7标注层`。

## 二、能标什么

| 拾取对象 | 产出 |
| --- | --- |
| 两个端点/交点 | 线性或对齐标注（按两点关系自动判竖直/水平/对齐） |
| 圆/圆弧 + 其上一点 | 半径 `R…` / 直径 `⌀…`（按拾取位置判断） |
| 线段的两个端点 | 同上（线段点选模式） |

> 更复杂的标注（剖视符号、向视图、局部放大、焊接、引线、形位公差、基准、角度、弧长、粗糙度）
> **不走 `D`**，走引导线：见 `06-引导线标注.md`。

## 三、AI 侧配方

```jsonc
// 触发（进交互态；AI 侧通常只在"人类会用鼠标点"的场景用）
{ "op": "run", "request_id": "d1", "document_id": 1, "revision": 5, "cmd": "D" }
// 之后每次"点"用带坐标的 run 送进去（坐标 = 世界坐标 x,y）
{ "op": "run", "request_id": "d2", "document_id": 1, "revision": 5, "cmd": "0,0" }
{ "op": "run", "request_id": "d3", "document_id": 1, "revision": 5, "cmd": "45,0" }
// 结束
{ "op": "cancel", "request_id": "d4" }
```

> 真正的"点坐标喂给交互命令"取决于宿主版本；**AI 批量标注更推荐用引导线 + `GDIM`**（见 `06`），
> 因为引导线是实体（可以先画好、再一条条生成标注，全程确定性）。

## 四、坑

1. **没跑 `OCSM` 初始化** → 样式缺失，标注字高/颜色不对。先 `OCSM`。
2. **点在别的图层也没关系**：标注产出统一进 `7标注层`。
3. **尺寸太小/太挤**：改标注样式（`OCSM_GB`）的全局比例或文字高度，别一个个改标注。
4. **`D` 在交互中**：这时输入的数字会被当成坐标，想切图层先 `Esc`。

## 五、验证清单
