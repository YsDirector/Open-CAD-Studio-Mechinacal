# 13 任务启动协议（**每张图开工前先做这个**）

> 用户 2026-09-15 定的口径：**除非孔/外形已经给好、只需要补件，否则按正常设计顺序走；
> 推到最前面就是"向用户索要设计输入"。知识是层层嵌套的。**
> 本文件对**所有** OCSM 任务生效（零件图、装配图、标注、明细表都一样）。

## 一、第一件事：把任务分类（决定后面走哪条路）

| 类型 | 判据（怎么认出来） | 走哪条路 |
| --- | --- | --- |
| **A 补全 / 逆向** | 图上**已经有孔/外形/板厚**，用户说"补个螺栓""按这个孔配""把尺寸标上" | 从**已有几何**读条件（孔径、板厚、轮廓）→ 反推规格 → 命令执行（`OCSMJOINT`/`XL`/`GDIM`…）。**上层约束按假设处理，并列出假设** |
| **B 从零设计** | 只有功能需求（"把这两块板连起来""设计这个箱体/油缸"） | 走**正常设计顺序**：**先向用户索要设计输入**（见 §二），再逐层往下算 |
| **C 抄图 / 转图** | 有对照图/原图/DXF | 几何从图上量；规格按图注；**国标差异（画法/字体/图层）先问再改** |
| **D 改图 / 修订** | 已有图纸要改 | 先读现状（`ocs_read state/query`）→ 只改要求的部分 → **不推翻未确认的既有约定** |

**判据不清就问一句**（"这个 Ø10 孔是给定的，还是我可以调整？"）——问错的代价远小于猜错的代价。

## 二、B 类（从零设计）：**第一步是索要输入**

按下面清单逐项问（一次问一批，别挤牙膏；用户答不出的就记成
**"假设 X（待确认）"**，并在交付时列出）：

1. **功能与载荷**：这连接干什么用？受什么力/力矩（大小、方向、静/交变）？有内压/密封要求吗（漏了会怎样）？
2. **环境**：温度范围、振动/冲击、腐蚀/介质、室内外？
3. **结构与空间**：被连接件材料与厚度、**是否已有孔**、可用螺栓数量与布置、扳手/装配空间、重量限制？
4. **约束与规范**：强度等级或防松要求（安全关键？）、企业/行业规范、**必须用现有物料吗**、批量与成本？
5. **交付形态**：零件图/装配图/明细表/技术要求？图幅与比例？给谁看（校审/加工）？

> 这五项对应设计链的顶层输入（见 §三）：**载荷 → 预紧力 → 螺栓数量/规格/等级 → 孔径 → 承压 → 力矩 → 材料/热处理 → 图形**。

## 三、知识是**层层嵌套**的（每层：输入 → 输出 → 回流）

```
① 工况载荷        输入：功能/载荷/密封/环境     输出：需要的最小夹紧力 F_req
② 连接设计        输入：F_req + 空间/数量        输出：n × M × 等级（强度校核）
③ 被连接件校核    输入：螺栓规格 + 材料 + 孔径   输出：p ≤ p_G？（承压/压溃）
④ 装配参数        输入：允许 F（取螺栓/基体小者） 输出：拧紧力矩 T + 方法（散差）
⑤ 材料与热处理    输入：④ 的应力水平 + 环境      输出：等级↔热处理、表面处理
⑥ 图样            输入：全部决策                 输出：XY 图形 + 标注 + 明细表 + 技术要求
```

**嵌套原则（三条，务必遵守）**：

1. **缺上层输入 → 回到上层去要**，不要在缺输入时凭"常见做法"一路往下推。
   例：不知道载荷，就不要直接报"用 8.8 级 M8"——可以给"常见默认 + 依据 + 待确认"。
2. **每层都会回流**：承压不过 → 加平垫/增孔数/换材料 → **回到第②层**重选；
   力矩散差大 → 改方法或加余量（第④层）；环境腐蚀 → 回第⑤层改材料。
3. **逆向路径要标注**：用户只给了下层条件（"就这个 Ø10 孔""必须是 M8"）→
   明确说"这是逆向路径：上层约束我按 X 假设"，并把假设**写进交付说明**。

**A 类（孔已给）最短路径**（今天就能做，属逆向）：

```bash
# 1) 读图上条件：孔径、板厚、跨距
python3 tools/crush_check.py M8 8.8 hex_ab dh=10 mat=6061    # 用实际孔径/材料核承压
# 2) 落图（件链 = 决策结果）
OCSMJOINT at 50,10 rot -90 bolt=hex_bolt_b_full:8 plate=10 plate=10 \
          washer=washer_971:8 nut=nut_c41:8
# 3) 交付说明里写清假设（上层载荷未给，按常规连接处理；材料按图注）
```
