# 01 初始化与图层

> 空白图第一件事、图层/线型/样式不对时的修复手段。

## 一、`OCSM` — 初始化

```
命令：OCSM
```

做四件事（缺什么补什么，**幂等**，可反复跑）：

1. **线型**：`CENTER2`、`DASHED2`、`DIVIDE2`（线型必须先于图层，否则 DWG 写出丢线型名）。
2. **图层**：`1轮廓实线层` … `10引导线层`（见 00 总览的图层表），颜色/线型/线宽按国标分工。
3. **文字样式**：`OCSM_GB`（国标字体，标注射高 5）。**旧图救字体**：同名 `OCSM_GB` 已在、但 TrueType 字体为空时，按插件口径把字体补上（已有非空字体**绝不覆盖**——哪怕不是我们的字体）。
4. **标注样式**：`OCSM_GB`（参数取自标注示例 dwg 的 Mechanical，字体换 `OCSM_GB`），并设为**当前样式**。

成功输出示例：`OCSM 初始化完成：新增图层 N 个、线型 N 个、文字样式 N 个（OCSM_GB）、标注样式 N 个（OCSM_GB，当前样式）。数字键 1-10、TF、D 已就绪。`

> 初始化本身是**文档改动**（表变更宿主不自动入撤销栈），插件自己声明了撤销点 "OCSM 初始化"。

### 新建空图纸自动初始化（旧图纸不动作）

新建图纸后**不用再手打 `OCSM`**：插件在每条命令分发前用严格启发式判断，三条全满足才自动跑一遍上面的初始化：

1. **没存过盘**（`document_path` 为空 —— 打开/另存过的旧图一律不动，**空白文件也算老图**）；
2. **没有任何实体**（有任何内容一律不动）；
3. **没有任何 OCSM 痕迹**（10 个图层里一个都没有，且没有 `OCSM_GB` 文字/标注样式）。

命中后自动执行与手动 `OCSM` **完全相同**的初始化（同一个撤销点 `OCSM 初始化`、同一套图层/线型/样式，可 Ctrl+Z 撤销），
回显 `新建图纸：自动执行 OCSM 初始化（旧图纸不会自动初始化）。`，然后照常执行你输入的命令
（如 `OCSMSHAFT`/`OCSMGEAR`，不会再被「先运行 OCSM」拦下）。

> **旧图纸不动作**：哪怕只是一个点、或空白但存过盘，都不会被自动初始化；
> 需要初始化时手打一次 `OCSM` 即可（对旧图的唯一入口）。
> 若自动初始化后被 Ctrl+Z 撤销，下一条命令会按同样三条判据再次补上。

> 实现依据：宿主没有「文档新建/打开」事件（`HostNotification` 只有变更/选择/关标签页），
> 所以走上述启发式（安全优先）；触发点 = 命令分发前，复用 `cmd_init` 的初始化主体。

## 二、数字键 1–10 — 切层 / 移层

| 情形 | 行为 |
| --- | --- |
| **没有选中对象** | 把**当前图层**切到该层（输出：`当前图层已切换到「N…」`） |
| **有选中对象** | 把**选中对象移到该层**（当前图层不变，记撤销，**保留选择集**） |

所以"把这几条线挪到中心线层"= 选中线 → 按 `3`；"接下来画虚线"= 不选任何东西 + 按 `4`。

## 三、颜色/线型/线宽一律 ByLayer

- 实体颜色 = ByLayer，线型 = ByLayer，线宽 = ByLayer。
- 需要区分粗细/线型时**改图层**，不要逐实体刷。
- 判据：`ocs_read op:"query"` 看实体的 color/linetype/lineweight —— 出现具体值（如 3=绿）就说明有人手刷过，
  应改为 ByLayer 并把实体移到正确图层。

## 四、AI 侧操作配方（初始化一张新图）

```jsonc
// 1) 新建/确认文档，读状态
{ "op": "read", "ocs_session_id": "...", "op": "state" }          // 拿 document_id / revision
// 2) 跑初始化（run 里直接给插件命令名）
{ "op": "execute", "request": { "op": "run", "request_id": "init-1",
  "document_id": 1, "revision": 7, "cmd": "OCSM" } }
// 3) 切层画线（数字键或带内联坐标的命令）
{ "cmd": "1" }                                                    // 当前层 = 1轮廓实线层
{ "cmd": "LINE 0,0 100,0" }                                       // 直线可内联坐标
// 4) 核对
{ "op": "read", "op": "query", "parameters": { "type": "Line", "layer": "1轮廓实线层" } }
```

## 五、坑

1. **没跑 `OCSM` 就标尺寸**：文字样式/标注样式缺失 → 标注回退默认参数（文字变图层色、字高不对）。
   修复：跑一次 `OCSM`，再用 `D2G`/重新生成标注。
2. **数字键在"命令进行中"无效**：交互命令（如 `D`、放置态）进行时，输入会被当成点/参数；
   先 `Esc`（MCP 侧 `op:"cancel"`）再切层。
3. **图层名务必用插件给的 10 个**：自建图层不会被"标注/符号"命令识别（例如 `7标注层` 之外的标注不会被 `ME` 编辑）。
4. 图层模板缺失时报 `OCSM: 图层模板缺失。请先运行 OCSM 初始化。` —— 就是没初始化。

## 六、验证清单

- [ ] `ocs_read op:"commands"` 能看到 `OCSM` 命令（插件已加载）。
- [ ] 初始化输出里有"标注样式 OCSM_GB（当前样式）"。
- [ ] 画一条线后 `query` 看它落在 `1轮廓实线层` 且 color/linetype = ByLayer。
