# 06 引导线标注（`GDIM` / `OCSMDIMGULIDE`）

> OCSM 的标注主干：**先在 `10引导线层` 画"意图几何"，再让命令按它生成国标标注**。
> 尺寸、剖视、向视、局部放大、角度、弧长、焊接、引线、形位公差、粗糙度全走这条路。

## 一、流程

```
1) 画引导线（10引导线层；线型/颜色无所谓，该层默认关闭不打印）
   类型不同，画的几何不同（见下表）
2) 选中那条引导线
3) GDIM            （= OCSMDIMGULIDE）→ 打开「标注配置」窗口
4) 窗口里：选类型/样式/文字/对齐参数 → 看预览
   「应用」        = 只把参数写回引导线（引导线带超链接 URL）
   「应用并刷新」  = 生成真正的标注实体（7标注层 / 符号进 8符号标注层）
5) 要改：选中标注 → ME（= OCSMEDIT）→ 同一窗口改参数 → 应用并刷新（删旧重建）
```

- 没有选中引导线 → `OCSM: 请先选中一条引导线（10引导线层 的直线或两段多段线）。`
- 引导线形状不支持 → `OCSM: 引导线必须是直线（LINE）、多段线（PLINE，2 顶点以上）、圆（CIRCLE）、圆弧（ARC）或矩形（RECTANG）。`

## 二、引导几何契约（**这条线要画成什么**）

| 类型（TYPE） | 引导几何 | 语义/参数 |
| --- | --- | --- |
| `LINEAR` 线性/对齐 | 1 条 **LINE** | 两端点 = 标注点；参数：对齐 `A/H/V` + 偏移 |
| `RADIAL` 半径 | 1 条 **LINE** | 起点 = 圆心，终点 = 圆周方向；参数：偏移 + 文字 |
| `DIAMETER` 直径 | 1 条 **LINE** | 起点 = 圆心，终点 = 圆周方向（可穿到对侧） |
| `ARCLEN` 弧长 | 1 条 **ARC（弧本身）** | 弧自带中心/半径/起止角 → 弧长与包角自足 |
| `ANGLE` 角度 | 1 条 **两段 PLINE** | 转折点 = 角顶点，两段 = 两条边（可标锐角或折角） |
| `SECTION` 剖视 | 1 条 **PLINE（可折线）** | 剖切路径；支持旋转剖/阶梯剖；参数：字母 + 剖视图放置坐标 |
| `DETAIL` 局部放大 | **CIRCLE / 矩形 / PLINE** | 圈选区域；参数：引线旋转角 + 放大图放置坐标 + 倍数 + 字母 |
| `VIEW` 向视图 | 1 条 **LINE** | 箭头方向线；参数：字母 + 方向 |
| `WELD` 焊接 | 1 条 **两段 PLINE（3 顶点）** | 顶点1 = 焊缝箭头点、顶点2 = 拐点、顶点3 = 基准线末端（四向吸附主轴） |
| `LEADER` 引线 | 1 条 **两段 PLINE（3 顶点）** | 顶点1 = 箭头点、2 = 拐点、3 = 肩线末端 |
| `BALLOON` 序号 | 1 条 **两段 PLINE（3 顶点）** | 顶点1 = 指针点（画圆点）、2 = 拐点、3 = 肩线末端（**必须水平**）；参数：序号条目列表 + 扩展方向（横/纵）+ 插入冲突开关；一个组可含多个序号（横排 V 形折线连 / 纵排竖线连）。详见 `14-序号标注.md` |
| `RGH` 粗糙度 | 块参照（INSERT） | 粗糙度符号库；参数：形状 + `Ra` 值 |
| `GD&T` 形位公差 | 1 条 **PLINE** | 公差框位置；参数：符号 + 公差值 + 基准（URL query JSON） |
| `DATUM` 基准 | 1 条引导几何 | 基准符号（1996/2008 两种画法） |
| `TOLERANCE` 尺寸公差 | 依附尺寸标注 | 代号模式（`H7`）或极限偏差模式（`+0.021/0`），配合表 ISO 286 |

> 一句话记法：**直线的两端点就是尺寸界线的起点；两段多段线是"箭头 → 拐 → 肩"的引线类符号**。

## 三、生成物与图层

| 产出 | 落在 | 说明 |
| --- | --- | --- |
| 尺寸标注（线性/半径/直径/弧长/角度） | `7标注层` | 用 `OCSM_GB`（或 `OCSM_GB_xN`）标注样式 |
| 符号类（粗糙度/焊接/引线/形位公差/基准/向视/剖视字母/局部放大） | `8符号标注层` | 多为**匿名块** `*X{n}` + INSERT |
| 引导线本身 | `10引导线层` | 保留（带 URL），可反复"应用并刷新"；该层不打印 |

## 四、AI 侧配方

```jsonc
// 1) 画引导线（直线型，两点在模型空间）
{ "op": "run", "request_id": "g1", "document_id": 1, "revision": 20, "cmd": "10" }        // 当前层=引导线层
{ "op": "run", "request_id": "g2", "document_id": 1, "revision": 20, "cmd": "LINE 0,0 45,0" }
// 2) 选中它（用句柄）
{ "op": "read", "op": "query", "parameters": { "type": "Line", "layer": "10引导线层" } }   // 拿 handle
{ "op": "run", "request_id": "g3", "document_id": 1, "revision": 21, "cmd": "SELECT 2A" } // 或由宿主设置选择集
// 3) 开配置窗口（人类在窗口里定类型/文字/偏移 → 应用并刷新）
{ "op": "run", "request_id": "g4", "document_id": 1, "revision": 21, "cmd": "GDIM" }
// 4) 核对：标注实体 + 超链接（引导线上的 URL）
{ "op": "read", "op": "query", "parameters": { "type": "Dimension" } }
```

- HTTP 层（窗口实际用的接口）：`GET /guide.html?handle=<十六进制句柄>&tab=<图纸号>`（配置页，`tab=` = 本窗口钉在哪张图上）、`GET /api/guide?handle=…[&tab=N]`（读记录）、
  `POST /api/apply`（只写超链接）、`POST /api/apply_refresh`（生成/刷新标注）；两个 POST 可带 `"tab":N`（页面就是这么发的）。
- **AI/脚本直连（2026-09-15 起已修好宿主路由：插件 HTTP 看的就是"当前活动图纸"）**：
  `GET /api/mcp` 发 `{"method":"get_guide","params":{"handle":"6F"}}` 读几何/参数；
  `POST /api/apply_refresh` `{"handle":"6F","url":"http://127.0.0.1:23751/DIM/LEADER/0?lu=…"}` 生成。
  注意 `list_guides` **只列已配置过参数（`PE_URL` 带 `/DIM/`）的引导线**，刚画的裸引导线不在内 ——
  所以 AI 的套路是：`ocs_read op:"query"`（`10引导线层`）拿句柄 → `get_guide` → `apply_refresh`。
- AI 若要做"全自动标注"：可以自己写引导线 + 直接 `POST /api/apply_refresh` 带参数 JSON（等价于人在窗口里点）。
- **焊接工艺代号（GB/T 5185）快捷下拉（2026-09-16）**：焊接面板尾部注释下方，「工艺代号」下拉列出
  GB/T 5185-2005 全部代号（10 组 145 项：1 电弧焊/2 电阻焊/3 气焊/4 压力焊/5 高能束焊/7 其他/8 切割气刨/9 钎焊/旧代号），
  选项显示「代号 名称」（如「111 焊条电弧焊」），选中后**尾部注释只写数字代号**（如 `111`）；
  再选一个自动空格并列（组合工艺，如 `111 12`），尾部开关自动打开并锁定；选完下拉复位，尾部注释仍可手改。
  免重启预览：`python3 tools/guide_gui_proxy.py`（23752 端口，HTML 取仓库最新版，/api 透传运行中插件）。

## 五、坑

1. **引导线必须先在 `10引导线层`**：`GDIM` 只认这一层（选错层的线会报"请先选中一条引导线"）。
2. **类型与几何不符**：如把 1 段 PLINE 当焊接引导（焊接要 3 顶点两段）→ 报错或画歪。
3. **改完参数忘"应用并刷新"**：只"应用"= 只写了超链接，图上还是旧标注（或根本没有标注）。
4. **改动是替换式的**：`ME` + 应用并刷新 = 删旧标注、按原引导几何重新生成 → **不要手动编辑生成的标注**，
   下次刷新就没了。
5. **比例换图框后**：旧标注仍用旧样式；新标注用新样式。要统一 → 用 `D2G` 或重生成。
6. **文字外移**（线性标注把文字拖到尺寸线外）：尺寸线会沿轴延伸到文字下方（GB/T 4458.4 画法，已实现）。
7. **配置窗口是「钉在图纸上」的（2026-09-16 修）**：插件进程（与端口）比一张图纸活得久，所以窗口打开时会把
   图纸号写进 URL（`/guide.html?handle=0x2A&tab=3`），之后每一次读/写都只投给**那张图**。
   同样的规则适用于零件库（`/parts`）、螺栓副装配（`/joint`）、表面粗糙度（`/rough.html`）、
   明细表编辑器（`/bom.html`，命令 `BOMEDIT`）窗口。
   - **`Ctrl+点击` 只能落在带地址栏的浏览器页签上**（宿主 `sys::open_url` → `xdg-open`，插件拦不到）：
     插件看到这种“外部打开”会**再补一个 app 窗口**，并把那个页签换成「已在新窗口打开」提示页
     （已开着同一窗口就不会重复开）。所以 Ctrl+点击的最终效果也是独立窗口。
   - **关掉某张图后，它的旧窗口一动手就立刻报**「这个窗口对应的图纸（标签页 N）已经关闭了 ——
     请重新运行 GDIM / ME 打开新窗口」（HTTP 409）。这是**故意的**：旧窗口不会再（等 5 s 后）
     把标注写到别的图上。
   - 多张图可以各自开着窗口，互不串图。
   - **不带图纸号的请求**（`Ctrl+点击` 标注链接、AI/MCP 直连 `/api/guide`、`/api/apply_refresh` 等）
     跟**当前活跃图纸**走 —— 插件听宿主的 `SelectionChangedV4` / `DocumentTabClosed` 通知，
     所以你只管切标签页（不必跑命令）它就知道你在看哪张图。
     注意一个前提：插件只能对**跑过至少一条 OCSM（或任意）命令**的标签页发请求；刚打开就
     直接 `Ctrl+点击` 时可能报「当前活跃图纸还没跑过 OCSM 命令」(HTTP 409) —— 在该图上
     随便跑一条命令（如选中标注 `ME`）即可，之后一切正常。

## 六、验证清单

- [ ] 引导线在 `10引导线层`；有 URL 超链接（`read` 记录里的 hyperlink）。
- [ ] "应用并刷新"后出现标注/符号实体，图层正确、样式为 `OCSM_GB*`。
- [ ] 选中生成的标注能再 `ME` 打开同一窗口（说明带 `OCSM_EDIT` 记录）。
- [ ] 截图核对符号朝向/文字位置（国标要求：字头朝上、引线不过文字）。
