# 10 明细表与 BOM（`BOM` / `BOMCFG`）

> 把标准件的 XDATA 汇总成图上的明细表。

## 一、命令

| 命令 | 别名 | 作用 |
| --- | --- | --- |
| `OCSMBOM` | `BOM` | **建表 / 刷新**明细表；可带参数：`BOM 30` = 本次首列先排 **30 行** |
| `OCSMBOMCFG` | `BOMCFG` | **配置**（列/表头/格式等），同样可带行数参数 |
| `OCSMBOMEDIT` | `BOMEDIT` | **打开网页编辑器**（chromium 独立窗口；见 §五）|

- 数据来源：图纸里标准件 INSERT 的 **XDATA `OCSM_PART`**（族/规格/标准号/材料/重量…）
  → 所以**不要炸开标准件**，也不要手画螺栓外形（那样统计不到）。
- 表体是**行块重复插入**（每行一个块实例），表头在整表最上方；行带 ATTDEF 属性（序号/代号/名称/数量/材料/重量/备注…）。

## 二、位置规则（从图框量出来的，换图框要重对）

以 `a3_landscape.dwg`（A3 横式，**180×45** 标题栏 + 左侧竖向附加栏）为例：

| 边 | 基准 | A3 横式实测 |
| --- | --- | --- |
| **右边** | 图框**内框右边**（=标题栏右边） | `x = 390` |
| **左边** | 标题栏**左边**（不延伸到左侧附加栏） | `x = 210` |
| **宽** | = 标题栏宽（本图框 **180 mm**，注意不是 200） | 180 |
| **底边** | 标题栏**上沿**，紧贴 | `y = 45`（首行 45→57） |
| **行序** | **自下而上**累积：序号 1 在最下、紧贴标题栏；表头在最上方 | — |
| **高** | 随行数向上生长（首期一行占位高 8 mm） | — |

通用规则：**右边界对齐内框右边；宽度 = 标题栏宽；底边贴标题栏上沿**。

## 三、序号球标（Balloon）

- 明细表三件套 = 表格 + 表头 + **序号球标**（把每个件的序号引到装配图上）。
- 球标与表格的**唯一耦合点 = 序号**：序号在表格里定好，球标指向对应件；改序号要两边同步。

## 三·五、与序号球标的联动（`BOMSYNC`）

`BOM` 是"按零件台账建表"（序号 = 行号）；装订了**序号球标**之后，用 **`BOMSYNC`**
按球标重排（也能在建/改球标时自动跑）：

- 行 = 球标组的每个条目 + 未被引用的聚合零件（沿用旧表序号，否则自动接号）；
- **同一序号被多个球标引用 → 数量 +1**（总重跟着算）；
- 勾了「插入序号」而造成冲突时：已有的受影响球标整体 +1，表跟着重排；
- 行序按**序号升序**、自下而上（序号 1 在最下）。

> 一句话：**序号是球标与表的唯一键**。`BOM` 建表（台账视角）、`BOMSYNC` 对号（球标视角）。

### 手改保护（用户 2026-09-15 定案）

同步是**替换语义**（删旧行重建），所以手改必须有保护，否则会被算出来的值覆盖：

| 列 | 规则 |
| --- | --- |
| **序号** | **永不锁**：由取号/球标规则掌握，同步总是重算 |
| **数量** | **可开关的锁**：没锁就按规则算（件数/球标引用次数）；锁了就**始终用锁定值** |
| 图号 / 名称 / 材料 / 单重 / 备注 | **非空即保留**（"无法解开的锁"）：行一旦存在，非空字段永不被覆盖；只有**空白格**才写新值 |

- **锁命令**：`BOMLOCK <序号|图号> [数量|off]`
  * `BOMLOCK 5` → 按行上现值锁（我手改过，别覆盖）
  * `BOMLOCK 5 3` → 数量改成 3 并锁（`总重` 自动 = 单重 × 3）
  * `BOMLOCK 5 off` → 解锁，下次同步重算
- **解锁重置的另一条路**：把那一行**删掉**，下次同步会按规则重新建（这时"新建时传入"才生效）。
- 总重是**算出来的**（单重 × 数量），永远跟着数量走，不算手改。
- 锁定行会出现在同步报告里：`N 行数量已锁定，未覆盖：…`（不静默）。
- xlsx 侧见下一节（**已实现**）。

## 三·五·五、单元格文字自动压缩（列宽自适应）

明细表的列宽是**模板定死**的（行块里的竖直分隔线 = 0/11/48/81/92/127/138/150/180），
而 CAD 的文字**不会自动缩排** —— 内容一长就压到邻格。所以写单元格时按列宽自动压缩：

| 步骤 | 做法 |
| --- | --- |
| ① 量宽 | 按**模板实况**（字型 `OCSM_GB`、字高 5.0、宽比 0.7）算：中日韩 **1.15 em**、拉丁/数字 **0.8 em**（图上像素实测校准，取保守值），再乘实际宽度因子 |
| ② 只压宽 | 超宽只压**宽度因子**，字高**不动（2026-09-16 用户定案：全表统一字高）**；目标宽 = 可用宽 × **0.9**（可用宽 = 列宽 − 2.5），宽比**不设下限** → 保证永远压进格内、绝不到邻格 |
| ③ 提醒 | 压到 **< 名义 × 0.7** 就算「太扁」：命令行点名 `OCSMBOM: … 横向压得偏扁：名称「…」41%（建议加宽该列 / 缩短文本）` |

实况对照（模板字高 5.0 **全表统一不压**，只算宽比）：

| 格 | 内容 | 列宽 | 结果（宽比 0.7 →） |
| --- | --- | --- | --- |
| 序号 | `1` | 11.0 | 不动 |
| 图号 | `GB/T 5780-2016` | 37.0 | 略压 |
| 名称 | `六角头螺栓 C级 M8x35` | 33.0 | **0.41（太扁，点名）** |
| 数量 | `1` | 11.0 | 不动 |
| 单重 | `0.018` | 11.1 | 压（太扁，点名） |
| 总重 | `0.018` | 11.9 | 压（点名） |

- 列宽从**行块几何**里读，不是写死 —— 你改模板（加宽图号列等）后自动跟着变。
- 只动**每一行的属性实体**（INSERT 里的 ATTRIB），**不改块定义** —— 每行各行其是。
- 想验证解析对不对：`cargo test -p ocs_ocsm --lib dump_row_template_widths -- --ignored --nocapture`
  （读 `bom/OCSM_BOMROW.dwg` 打印列宽 + 常见内容的压缩结果）。

## 三·六、外部 `.xlsx` 联动（`BOMXLSX` / `BOMXLSXI`）

```
BOMXLSX                    → 导出到「图纸同名-明细表.xlsx」（同目录），并在表头挂链接（Ctrl+点击打开）
BOMXLSX D:/表.xlsx          → 指定路径（省扩展名自动补 .xlsx；路径大小写原样保留）
BOMXLSX D:/表.csv          → 指定 `.csv` 则导出 CSV（UTF-8 带 BOM，Excel/WPS/文本编辑器都能开）
BOMXLSXI                   → 从表头链接指向的文件导入（没链接就用默认路径）
BOMXLSXI D:/表.xlsx         → 指定文件（也收 `.csv`）
```

**先存盘再画序号**（重要）：xlsx 默认落在**图纸同目录**，所以新图没存过盘时会落到默认目录
（**系统临时目录** `/tmp/OCSM/明细表.xlsx`；Windows 为 `%TEMP%\OCSM\`——走 `std::env::temp_dir()`，跨平台一份代码）。插件在三处会提示：

* 画序号**之前**：GDIM 窗口的「序号」面板上有一行橙色提示；
* 画序号**落地时**：命令行提示"本图还没存过盘"（每个标签页只提一次，不挡主流程）；
* `BOMXLSX` 导出时：明说文件落到哪儿、怎么改。

**列序**（前 8 列 = 图纸明细表本体；第 9 列只在这个文件里，**不进图纸表格**）：

```
序号 | 图号 | 名称 | 数量 | 材料 | 单重 | 总重 | 备注 | 锁定数量
```

*「锁定数量」：空 = 不锁；`Y`/`是`/`1`/`√` = 锁为**同行数量**；数字 N = 锁为 N。

**导入规则**：

| 情况 | 行为 |
| --- | --- |
| 文件单元格**非空** | 覆盖图纸（文件是显式的编辑通道）|
| 文件单元格**空白** | 保留图纸现值（不会把已有内容擦掉）|
| 文件里**没有**的序号 | 保留图纸那一行（导入只改不删）|
| **总重**列 | 忽略输入（= 单重 × 数量，算出来的）|
| 数量 ≠ 上次导出时的值（基线） | 认为**人手改过** → **自动上锁**，以后同步不覆盖 |

- 导出时会把每行当时数量记进行块 XDATA（`OCSM_BOMXEXP`）——这就是"手改即锁"的比对基线；
  导入成功后基线自动刷新，所以同一份文件重复导入不会重复上锁。
- **已存在的行永远不会被同步自动删掉**（球标拆了/零件删了也一样）：要让某行消失，**手工删掉它**。
- 写出的 xlsx 是标准文件（zip + SpreadsheetML，inlineStr），Excel / WPS / LibreOffice 都能打开；
  读的时候也认它们重写后的 sharedStrings / 数字单元格 / 跳号单元格。
- 插件**不依赖** LibreOffice/Excel/Python：读写都在插件里做（`flate2` + `crc32fast` + `quick-xml`）。

## 五、网页编辑器（2026-09-16 第四期）

两种打开方式（2026-09-16 补的）：

- **`OCSMBOMEDIT` / `BOMEDIT`**（命令，推荐）→ 直接开 **chromium `--app` 独立窗口**（和标注配置窗一样干净），
  窗口 URL 带 `tab=<图纸号>` → 多张图各开编辑窗不串表；
- **Ctrl+点击表头/行块** → 宿主只会用 `xdg-open` 开它，落到**带地址栏的浏览器页签**里；插件看到这种
  “外部打开”会**再补一个 app 窗口**，并把那个页签换成「已在新窗口打开」提示页（可直接关掉）。
  没有 app 窗口时只补一个；已经开着（心跳）不会再开重复窗口。

明细表编辑页（图纸 = 唯一真源）：

- **读**：`GET /api/bom_get` —— 扫行块（按序号升序）+ 锁/基线 XDATA + 未存盘状态 + 缺台账计数。
- **写**：网页里随便改（加行=手加件、删行、改格、锁），点「应用到图纸」整表一次重建（`fill_bom` 替换语义，
  一次 Ctrl+Z）；提交带**指纹**（行现状 + 图纸路径），打开网页后图纸被球标联动等改过 → **409 拒绝**并回传最新状态，防旧视图盖新图。
- **改序号（重排式）**：勾「改序号撞号时后续自动顺延」，撞号行自动 +1（保留前缀/位宽，A09→A10）；
  应用后端按「图号+名称+材料」身份映射**球标同步重编号**（复用球标 GUI 重建机制；对不上的行不动并告警）。
- **导出**：`POST /api/bom_export?fmt=xlsx|csv&name=…` → 字节走 JSON → 浏览器「另存为」（默认「图纸同名-明细表.xlsx」）；
  同时记下**导出基线**（行块 `OCSM_BOMXEXP`）。
- **导入**：页面文件选择器读 xlsx/csv 字节 → `POST /api/bom_import` → 复用 `BOMXLSXI` 合并规则
  （非空覆盖/空白保留/缺序号保留/**手改即锁**）。
- 锁的真相始终在图纸行块 `OCSM_BOMLOCK`；xlsx 里的「锁定数量」列只是导入导出的表现形式。
- 老图纸里指向 xlsx 文件路径的 PE_URL（宿主 `web_hyperlink` 只放行 http/https，永远点不开的死链接）
  会在端口刷新/建表时自动重写成 bom.html 链接；上次导出路径存 `OCSM_BOMXPATH`（`BOMXLSXI` 默认路径）。

## 六、坑

1. **没有标准件就没有内容**：手画的螺栓不会进表（没有 `OCSM_PART` 记录）。
2. **宽度不是 200**：这个图框的标题栏宽 **180** —— 按 200 排会超出内框（数字以 `bom/README.md` 为准，本页与代码同步：表宽 180、左边 x=210、右边 x=390、底边 y=45）。
3. **行数不够**：`BOM 30` 只是"本次首列先排 30 行"，实际行数由图纸里的件种类数决定；重跑会刷新。
4. **重量**：标准件的重量按体积×钢 7.85 g/cm³ 估算（见 `03`）；非钢材质要自己核。
5. **换图框**：位置基准变（内框右/标题栏宽/标题栏上沿），要重新摆。
6. **打开就是空的、得点一下刷新？** 那是页面开场脚本抛错了（`addEventListener('click', add)` 里的
   `add` 没定义 → 后面的 `reload()` 永不执行）。2026-09-16 已修，并加了静态检查测试拦截这一类。
