# 03 标准件库（`OCSMPART` / `XL`）

> 插螺栓/螺钉/螺母/垫圈/销，查国标规格。**不要手画标准件**。

## 一、两种用法

| 用法 | 命令 | 适合 |
| --- | --- | --- |
| **人类**：开窗口挑 | `XL`（= `OCSMPART`，**不带参数**） | 边看预览边挑规格、随手放置 |
| **AI/脚本**：一行直插 | `OCSMPART <族> <d> <l> [view 视图] [at x,y] [rot 度]` | 已知规格、批量、可回归 |

不带参数的流程（人类）：

```
OCSMPART            → 打开「OCSM 标准件库」窗口 + 进放置态
窗口里：左树选零件 → 右面选 公称直径 / 长度 / 视图 → 看预览 → 点「零件出库」
回图纸：点一下定位基点 → 移动光标旋转 → 再点落定（可连续，Esc 结束）
```

## 二、语法（AI 直插）

```text
OCSMPART <族> <直径 d> <长度 l> [view <视图>] [at x,y] [rot 度]

例：
OCSMPART hex_bolt_c 10 95 at 150,30 rot 0
OCSMPART nut_c41 8 0 at 150,-30            ← 螺母/垫圈只有 d（l 占位写 0）
OCSMPART washer_971 8 0 view main at 150,-40
```

- **族名**用下表的小写 id（也可用 `族=直径` 形式：见 `04`）。
- `view`：`main` 主视图 / `top` 俯视图 / `end` 左视图 / `section` 剖视（各族支持的视图不同，
  窗口里会列出来；不支持的视图会报错）。
- `at x,y`：基点落点（不给则用图纸里点选的"待放置点"，再不然原点）。
- `rot 度`：绕基点旋转角（`Insert.rotation` 内部是弧度，参数按**度**给）。
- `l`：螺栓/螺钉是要长度；螺母/垫圈/销（部分）忽略或按族含义使用。

### 结构要素（与标准件并列的另一棵树）

`XL` 窗口左侧是「结构要素」树：**d 自由输入**（不是固定规格下拉），已上架：

| 族 id | 名称 | 命令行 |
| --- | --- | --- |
| `detail_grind_od` | 磨外圆砂轮越程槽 GB/T 6403.5-2008 | `OCSMPART detail_grind_od <d> [b1 值] [at x,y] [rot 度]`（b1 缺省 = 该 d 档默认行） |
| `detail_thread_relief` | 外螺纹退刀槽 GB/T 3-1997 | `OCSMPART detail_thread_relief <d> P <螺距> [g1 值 g2 值 dg 值 r 值 alpha 值] [at x,y] [rot 度]`（P 必给） |
| `detail_spline_rect` | 矩形花键 GB/T 1144-2001 | `OCSMPART detail_spline_rect <规格代号 N×d×D×B> L <满齿段长> [de 值] [view front/side/section] [at x,y] [rot 度]`（表内规格 de 自动查表，表外必给） |
| `detail_hub_keyway` | 普通平键毂槽 GB/T 1095-2003 | `OCSMPART detail_hub_keyway <d> [len 毂长] [view main/side] [at x,y] [rot 度]`（b/t₂/r 由 d 查 1095 表；len 缺省 30） |

> **渐开线花键只在齿轮生成器 `OCSMGEAR` 生成**（XL 结构要素旧入口 2026-09-22 已移除，防两个入口）：
> 不带参数打开窗口，勾选顶部「花键模式」→
> 标准号/齿廓/基准直径 d_B + m/z/α/ha*/hf*/ρf*/cF*；同一「齿轮种类」开关切换外花键/内花键。
> 齿轮模式给标准号或 d_B 会明确报错；GB 下 d_B 不显示（本体系无此概念）。内花键与内齿轮同口径：
> **只有 剖视图 + 端视图，无侧视图**（用户定案）。详见 `16-齿轮.md` 第九节。

矩形花键的规格代号在 `XL` 窗口与轴生成器段表里都是**下拉选择**（GB/T 1144 表内 33 条，
末尾「自定义…」手输表外规格；选中自动带出 de/h/l 派生值，de 框可改 = 覆盖）。

轴生成器**不再提供**渐开线花键段（`INVOLSPLINE` 已于 2026-09-22 移除，用户定案「只在齿轮生成器生成」）；
轴上花键用矩形花键 `SPLINE`。XL 窗口里也已没有渐开线花键；引擎数据经目录顶层 `spline_engine`
仅供齿轮生成器的花键模式使用（预设 / DIN 5480-2 名义表 / 检验表 / 各体系模数）。

- 退刀槽几何照 GB/T 3-1997 图 2：台肩面竖线（到 `d/2+r`）→ R=r 圆角 → 槽底 `y=dg/2`（`x=r…g1`）
  → 30° 斜壁到 `(g2, d/2)` → 螺纹外圆示意段 5mm；`dg = d − 表 2 减量`；基点 = 台肩面与轴线交点。
- 退刀槽数据：表 2 单键 = 螺距 P（0.25…6，**无 0.2**）；`g1/g2/dg/r` 可覆盖；`alpha` 默认 30°（必须 ≥30°，实际斜壁更平时报错）。
- 预览（结构要素无 `l`，参数直接带在 query 里）：
  `GET /api/part_svg?family=detail_thread_relief&d=20&P=1.5`、`…&b1=8`（磨外圆）。
- **毂槽**（`detail_hub_keyway`，轮毂侧，用户定案「不是轴生成器的东西」）：
  `d`（孔径）→ `b`（1979 GB/T 1095 d 列）→ `t₂`/`r`（表 1；数据复用 `assets/keyway_gb1095.csv`）；
  两视图：`main` = 孔端面（孔圆弧缺键槽开口 + 两壁 + 槽底 + 两圆角 r），
  `side` = 纵向剖局部（毂长 × (d/2+t₂) 矩形 + `√(R²−(b/2)²)` sagitta 线）；
  键槽开口朝 +Y、中心线伸出 3；**图层统一到 OCSM 五层**（孔圆与键槽轮廓/侧视图轮廓全落 `1轮廓实线层`、
  中心线 `3中心线层`；与模板的 `0` 层不同，**有意偏差**——模板 0 层视为随手未分配）；
  **不打剖面线、不生成尺寸标注**；圆角默认取该档 `r_max`（模板 specimen b=8→0.25；`HUB_KEYWAY_R_PICK` 一处可切）。

### 平键（GB/T 1096 A/B/C 型、GB/T 1097 A/B 型）

平键族用**两参数模型**的 `d` 槽位承载**键宽 b**（`h` 查表派生），长度用 `l`
（`l=0`/省略 = 该档默认 L）。型别（A/B/C）编在族 id 里，`XL` 窗口里是**型别下拉**
（目录 `type_group` 渲染；换型别 = 换族，左侧树高亮/视图/规格下拉全部联动）。

| 族 id | 名称 | 标准 | 规格 | 视图 |
| --- | --- | --- | --- | --- |
| `key_1096_a` / `key_1096_b` / `key_1096_c` | 圆头普通平键 A/B/C 型 | GB/T 1096-2003 | b=2…50（20 档） | main 主 / top 俯 / section 剖 |
| `key_1097_a` / `key_1097_b` | 导向平键 A/B 型 | GB/T 1097-2003 | b=8…45（14 档） | main 主 / top 俯（模板无剖视图） |

命令行（`d` 槽位 = b）：

```text
OCSMPART key_1096_a 4 8          ← b=4、L=8（h 查表=4）
OCSMPART key_1096_b 22 0         ← b=22、L 省略（0 = 用表内默认 63）
OCSMPART key_1097_a 8 25         ← b=8、L=25（短键；L1/L2/L3 查表 = 13/12.5/6）
```

- **L 口径**：1096 系列 `6,8,10,…,400`（6/8 依用户素材补；在线 L 行自 10 起）＋ 约束
  `L < 10·b`（GB/T 1096-2003 注③）；1097 系列 `25,28,…,450`（嘉立创《导向平键的尺寸与公差
  (GB/T 1097-2003)》`new05232.htm` 长度表 26 档逐格核对）＋同样 `L < 10·b`。表内默认 L
  不合法时就近取合法值（1097 b=8/10 的 100 → 70/90）；下拉只列该 b 的全部合法 L。
- **⚠️ 1097 的 `L1/L2/L3` 由 `L` 查 GB/T 1097-2003 长度系列表派生**（26 档，JSON
  `partsKey1097{A,B}.json` 的 `length_rows`）：孔位 `±L1/2`、端距 `L3=(L−L1)/2`、断裂线
  `xb=−(L1/2−D/2−1)` 全部随 `L` 走，**不再用 specimen 固定值 `L1=60/L2=50/L3=20`**。
  **不插值、不外推**：`L` 不在表内（如 26/27/500）→ 明确报错并列出可选系列；
  `key_1097_length_for()/key_1097_length_checked()`；表内 `L2=L/2`、`L1+2L3=L` 有数据护栏。
  同页 `L0`（**轴上固定螺钉螺纹孔深，自键槽底向下**——装配剖视里该尺寸标在轴内；用户 2026-09-25 更正）
  与固定用螺钉 `d×L4`（`screw` 字段，GB/T 822/65）已入库；`d0` 是固定螺钉螺纹公称，
  `d1/D/h1/C1` 是键上孔。
- **1096 倒角按 b 分档，默认取该档范围下限**（用户 2026-09 新定案；与 1097 的 C 取下限同口径）：
  档位 = GB/T 1096-2003 表 1 `s` 行 —— `2~4: 0.16~0.25`｜`5~8: 0.25~0.40`｜`10~18: 0.40~0.60`｜
  `20~32: 0.60~0.80`｜`36~50: 1.00~1.20`｜`56~70: 1.60~2.00`｜`80~100: 2.50~3.00`；
  每行 `c_min/c_max` 存 JSON，实画取值切换点 = `partgen_keys::CHAMFER_1096_PICK`（Min 默认 / Max / Mid，改一处即可）。
  ⚠️ specimen b=2 按新口径画 **0.16**，源模板 DXF 画的是 0.2（在 0.16~0.25 内的中间值）
  → **已知 0.04mm 有意偏差**（举证页偏差④），不要为对齐模板改回 0.2。
- **⚠️ 1096 A 型参数表 PNG 末 4 行 h 印错**（32/20/22/25，像素级证实为源图误印）：
  库内取标准值 **20/22/25/28**（与 B/C 型、在线表一致），印刷值仅存 JSON 的 `h_printed` 备查。
- **1097 的固定方式 = 螺钉把键固定在轴上**（用户 2026-09-25 更正）：轴上是 2 个固定螺钉
  螺纹孔（`d0×L0`，自键槽底向下，118° 钻尖）；键上对应 `d1` 通孔 + `D×h1` 沉孔，
  安装孔距 `L1`、距端面 `L3`（都由 `L` 查长度系列表派生）。
  **⚠️ 概念不要互搬**：「起键螺孔」= GB/T 1096 附录 A 的概念（普通平键，把键撬出用）；
  「固定螺钉孔」= GB/T 1097（导向平键，把键固定在轴上）。旧注释把表列 `d0/L0`
  当“1097 起键螺孔”已作废（`L0` 真义见上）。
  **键零件主视的中央 d0 孔 = 通孔**（用户 2026-09-25 裁定：螺钉穿过键身；旧实现误用轴上
  `L0` 当孔底，多档 `L0>h` 会画出键外）；`L0` 保留在数据里、**不参与键零件几何**。
  （GB/T 1096 附录 A 另给普通平键的起键孔 M3…M20，本库暂未画。）
- **用户画法口径**：1097 主视图 = 右半剖 + 左半外形；**两半的分界线 = `2细线层` 规范 45° 断裂折线**

  4 段严格 45°、推广规则 `xb = L1/2 − D/2 − 1`，见 `break_1097()`）；螺纹小径
  3/4 圈画在 `2细线层`（源图在 `4虚线层`）；剖面线**全局 3.0 mm**（不照模板的 0.794/3.175）；
  **不生成尺寸标注**。

### 轴槽（轴生成器段表 KEY 列）

轴生成器把轴槽当**轴段类型**（与螺纹 `M`、矩形花键 `SPLINE` 同级，不是视图级）：在 `OCSMSHAFT`
窗口的**轴段表 KEY 列**上勾选后，给 **键型**（表驱动单下拉：`普通平键A型` / `普通平键B型` /
`普通平键C型` / `导向平键A型` / `导向平键B型`；**不再单出「导向」复选框**——用户 2026-09-25 收尾）、
**键长 L**（**所选键型的键长**；平键族 L 系列
∩ `L<10b`，下拉候选）、**位置 中置/端置**；**键尺寸 `b×h` 由该轴段直径 d 查 GB/T 1095 首列 d
自动定**（`assets/key1096_shaft_ranges.csv`，26 档，**选型依据**；h 跟 b 走），**只读显示在 KEY 列**
（例 `d25 → b8×h7 t1=4 · 槽长 18`）。`t1` 按 b 查 `assets/keyway_gb1095.csv`（GB/T 1095-2003 表 1）。
显式覆盖 `b8h7` 只作校验：必须落在该轴径档的标准配对上，否则明确报错。

```text
OCSMSHAFT S25 E25 L40 CH2@L KEY A 18 | S30 E30 L30     ← 中置 A（槽长 = L；d25 自动 b8×h7）
OCSMSHAFT S25 E25 L40 CH2@L KEY B 10 | S30 E30 L30     ← 中置 B：显示 A，槽长 = L_B + b = 18
OCSMSHAFT S25 E25 L40 CH2@L KEY C 14 @端 | S30 E30 L30 ← 端置 C（显示 C；槽长 = L + t1 = 18）
```

- **显示规则（用户 2026-09-23 口径）**：**常规侧视（中置）恒显示 A 型跑道形**（所选 A/B/C 都画
  双圆头，槽端都是圆弧、不出直棱）；**端置 B/C 显示 C 型**（平端朝开口 + 内端圆头 + 40° 导入线），
  端置 A 仍显示双圆头。显示长度用折算后的长度，保证显示的直段能容纳所选键。
- **L 自动折算（槽端圆弧半径 `b/2` 吃直段）**：用户只填**所选键型的键长**，程序自动算实际槽长：

| 所选键型 | 直段需求 | 中置（显示 A）L_eff | 端置（B/C 显示 C）L_eff | 实际槽长 |
|---|---|---|---|---|
| A 双圆头 | `L − b` | `L` | `L` | 中置 = L_eff；端置 = L_eff + t1 |
| B 双平头 | `L` | `L + b` | `L + b/2` | 同上 |
| C 单圆头 | `L − b/2` | `L + b/2` | `L` | 同上 |

  例（模板轴 d25：b8、t1=4）：想用 B 型键长 10 → 填 `KEY B 10`，中置实际槽长 18（显示 A 直段 10）、
  端置 `KEY B 10 @端` 实际槽长 18（显示 C 直段 10）。等价人工写法（旧口径）：中置用 A 填 `L_B + b`、
  端置用 C 填 `L_B + b/2` —— 两种写法得到同一几何。
  回归测试：`shaft::tests::keyway_display_rules_abc_and_bc_length_conversion` +
  `shaft::tests::b_key_maps_to_ac_keyway_length`（A/B/C × 中/端 弧心位与直段逐档断言）。
- **键型下拉 + 表驱动（用户 2026-09-25 收尾）**：键型与「导向」合并为一个下拉（后端
  `partgen_keys::KEY_STYLES` 表：`id/label/key_type/guided/standard/places/allow_double`，
  经 `/api/parts` 顶层 `key_styles` 下发；GUI 的下拉选项、位置约束、双槽可用性、信息行全由它驱动）。
  **加「楔形平键」等新键型：表加一行 + `shaft.rs` 按 `key_type`/`guided` 补画法分支**。
  **DSL**：新推荐写法 `KEY 导向A 25`（普通键仍 `KEY A 18`）；**旧写法 `KEY A 25 导向` 过时但可用**
  （等价映射，勿删）；ASCII 别名 `GUIDED_A`/`GUIDED_B` 也可。
  **JSON**：老 schema `{"type":"A","guided":true}` 不变（兼容读取）；另接受 `{"type":"导向A"}` 别名。
- **可选「双槽」（v7）**：绕轴心 **180° 对置**的第二个键槽（关于轴中线镜像；中置/端置都支持）——
  **仅剖视图体现**（常规侧视图不变，远侧槽不画）；剖视剖面线按“上下两环各带一个缺口”对称分区，
  两槽之间的中带一并填充。用途口径（用户 2026-09-23）：**可承受转矩约为单键联接的 1.5 倍**。
  DSL `KEY A 18 双槽`（`DOUBLE` 别名）/ JSON `"double":true` / 段表 KEY 列勾选；
  导向键型由 `allow_double=false` 自动禁用（表驱动）。
- **导向平键槽（GB/T 1097，2026-09-25）**：键型下拉选「导向平键A/B型」（DSL 推荐 `KEY 导向A 25`，
  旧 `KEY A 25 导向` 等价；JSON `"guided":true` / `"type":"导向A"`）：
  键型只 **A/B**（1097 无 C）、L 取 1097 长度系列（25…450 ∩ `L<10b`）、**槽长 = 键长 L**（固定键不折算）；
  **只有中置**（用户 2026-09-25 裁定：`@端` / `"place":"end"` 明确报错——端置是普通平键 KEY 的画法；
  GUI 端置选项禁用）；
  槽上自动画 **2 个固定螺钉螺纹孔**（`d0×L0` 自槽底向下、118° 钻尖；孔心距槽两端 `L3`，
  `L1/L2/L3` 由 L 查 26 档长度系列表）；与 `双槽` 互斥。常规侧视 = 键体（A 圆头 / B 平头，长 L）
  + 孔圈（小径实线整圆 + 大径 3/4 细弧，库内共有口径 = 模板换算 265°→185°）；
  剖视 = 槽底沿孔轮廓下凹 + 剖面线上环沿孔/下环平顶；
  不生成尺寸标注。模板 `~/桌面/OCSM/轴生成器-导向平键槽.dxf`；反解 `review/导向平键槽_几何反解.md`。
  **⚠️ 起键孔不属 1097**（那是 GB/T 1096 附录 A；槽上只有固定螺钉孔）。
- **段类型互斥（照既有实现风格）**：KEY 与 **GEAR / SPLINE / M / OV / RL** 不能同段——
  后端 DSL 解析 `shaft.rs:1908`、`:2004`，JSON `shaft.rs:2575/2655/2750`，`validate` `shaft.rs:2941`
  （KEY×GEAR/SPLINE）、`:2946`（KEY×M/OV/RL）；GUI `shaft_gui.html:510 enforceExclusive` 联动互斥 +

## 四、基点约定（放错位置的 90% 原因）

| 族 | 基点 | 轴向 |
| --- | --- | --- |
| 六角头螺栓/内六角圆柱头螺钉/内六角平圆头螺钉/内六角花形低圆柱头螺钉 | **头部支承面 × 轴线** | 杆朝 `+x`（`rot 0` 时杆朝右） |
| 内六角平端紧定螺钉 | **内六角端端面 × 轴线** | 拧入端在 `x=0`，平端朝 `+x` |
| 吊环螺钉 A 型 | **支承面 × 轴线** | 环心在 `+y` 侧、杆沿 `−y`（竖直） |
| 螺母（六角/圆/薄） | **端面 × 轴线** | 螺母占 `x ∈ [0, m]` |
| 垫圈（平/弹/止动） | **端面中心** | 占 `x ∈ [0, 厚]` |
| 挡圈（孔用/轴用） | **端面中心（轴线）** | 挡圈平面 ⊥ `x`，占 `x ∈ [0, s]` |
| 轴承（深沟球/圆锥/调心） | **端面中心 × 轴线** | 剖视：轴线 `y=0`、端面 `x=0` |
| 密封圈 FB 型 | **端面中心 × 轴线** | 剖面：轴线 `x=0`、端面 `y=0` |
| 销 | 端面/中心（见窗口里 `base_hint`） | 沿 `+x` |

> 两参数 GUI 模型：轴承用「内径 d + 宽度 B/T」、密封圈用「轴径 d1 + 外径 D」（同规格多外径的变体在长度下拉里选），
> 详见各族 `len_label`。

所以 `rot -90` = 杆朝下（头在上），`rot 0` = 杆朝右。

## 七、坑

1. **`l` 必须落在该族表内系列**：超出范围报错（例如 5783 M8 的 `l` 系列是表内档，
   不是任意值）。要按需求选长度 → 用 `04` 的 `OCSMJOINT`（它自己按供货系列取）。
2. **螺母/垫圈的 `d` 是螺纹规格**（M8 → `d=8`），不是内径/外径；它们的厚度取自国标表。
3. **视图选错**：垫圈"主视图"是**侧视轮廓**（平垫=矩形、弹垫=月牙），装配图里就该用 `main`；
   `end` 是端面圆圈。螺栓主视图 = 轴线水平的侧视。
4. **重复插会建重复块定义吗？** 不会：同名块复用（块名由族+规格决定）。
5. **别把标准件炸开**：炸开后 XDATA 与块名都没了 → 明细表统计不到、`OCSMEDIT` 之类也认不出。
6. **零件库窗口是「钉在图纸上」的**：窗口 URL 带 `tab=<图纸号>`，出库/插入只落在**开它那张图**
   （多张图各开窗口不串图；图被关后旧窗口会立刻报「窗口对应的图纸已关闭」）。规则见
   `06-引导线标注.md` §五.7。

  INSERT 缩放 = **1**（紧凑表，不需要整表缩放；与 NF/DIN 的 0.17 不同）。
- **同源**：取值与 GB 卡**同一份** `spline_tol::compute()`（不是另算一份）；计算书
  （`/api/card_report`）出「精简项（9 项）」节，与卡片 ATTRIB 逐项一致；表驱动：扩体系 =
  加一份字段表 + `CARD_TYPES` 一行 + 一个分派分支。

### 九·十二、精简版扩体系（NF / DIN / ANSI×4 / 齿轮，共 9 张；2026-09-27 用户点单）

- **口径**：与 GB 精简版同义 —— **只列基本参数 + 主要测量量、整列公差去掉**；一卡一方向；
  下拉统一归入**「精简版」分组**（`<optgroup>`）；卡 id：`NF花键精简表_内/外`、
  `DIN花键精简表_内/外`、`ANSI花键精简表_内/外_中文`、`ANSI花键精简表_内/外_英文`、`齿轮精简表`。
- **内容（各体系自身口径，不照搬 GB）**：
  * NF 内 = 执行标准·定心方式·m·z·a·齿根样式·加工方法·大径 Az·小径 D + 量棒 V / 跨棒距 G（11 项）；
  * NF 外 = 同上 9 项 + 跨测齿数 K / 公法线 W（11 项）；
  * DIN 内/外 = 标记·z·m·α + 齿根圆/齿根成形圆/齿顶圆（外卡对应齿顶圆/齿根成形圆/齿根圆）+
    量圆 D_M + 量圆距 M2/M1 极限（10 项）；
  * ANSI 内/外·中/英 = 类型·z·P·α·基圆·节圆·大径·小径 + 主要测量量（内 M/Dp、外 W/K；10 项）；
  * 齿轮 = m·z·α·变位 + 分度圆/齿顶圆/齿根圆 + 公法线 W / 跨齿数 K（9 项）。
- **表驱动实现**：共享引擎 `card_lite.rs` —— `LITE_CARDS` 9 行（块名/标题/完整卡 id/字段表）；
  取值/校验/表达式反解**全部投影自对应完整卡**（转调同一 `preview_json` → 按 key 挑项）；
  齿轮三圆由同一 `GearParams::d()/da()/df()` 补算。加卡 = 加一行 + 字段表，不复制计算代码。
- **块几何**：`OCSM_LITE_*`（GB 精简骨架同款：行高 6.89872、`OCSM_GB`、无 MTEXT、公差列不存在），
  行数随字段数；INSERT 缩放 = **1**。
- **同源/口径**：计算书（`/api/card_report`）出「精简项（N 项；与完整卡同一份计算）」节；
  查表查不到 →「—」**不外推**；完整明细仍用对应完整卡。
- **卡面文字随语言（③ 卡面批 i18n，2026-09-27）**：NF 精简两卡的标题与 11 行标签走 catalog
  （标题 `card.nf.lite.title.*`，行标签**复用全卡** `card.nf.label.*` + `label_symbol(family)` 拼
  符号——NF 大径/小径符号**随方向** `Az`/`Dee`、`D`/`Die`）；英文实体字宽见
  `en_label_width_factor()`（预算脚本 `i18n_检查/card_nf_width_plan.py`），
  英文长文字值（`Major dia. centering`）另用 `value_wf()` 压到 0.64。精简卡标签是 **TEXT**
  （有实体字宽，不需要 NF 全卡的 `\W` 内联码）。
- **GB 卡外花键量棒/跨棒距面板（2026-09-27）**：GB 外卡 21 项不变（模板忠实），但 GUI 面板
  **可用** D_Re/M_Re（GB/T 3478.6 §3.2；标准解 + 3 备选 + 手填），标题标注
  「**公法线为主、跨棒距备用**」；M_Re 与其极限只在面板出现（计算书不重复堆同一量）。
