# 17 孔生成器（`OCSMHOLE` / 短命令 `DK`）

> **前置要求**：先跑过 `OCSM` 初始化（建 10 图层 + 线型 + 文字/标注样式）。没初始化的图纸
> 执行 `OCSMHOLE` 会**直接拦下来并报缺什么**（与 `OCSMGEAR`/`OCSMSHAFT` 同口径）。
>
> 放置方式与 `OCSMSHAFT`/`OCSMGEAR` **完全一样**：窗口里点「确定」→ 回图纸点定位基点 →
> 移动光标旋转 → 再点落定（可连续，Esc 结束）。
>
> 输出只是**孔本身**（底孔壁 + 底锥 + 螺纹线 + 沉/埋头 + 中心线），**不画材料板轮廓**：
> 基点 = 孔口中心 × 材料表面，孔向局部 −Y；粗/细点的材料板与绿色剖面线只出现在窗口预览里。

## 一、两种用法

| 用法 | 命令 | 结果 |
| --- | --- | --- |
| 人用（推荐） | `OCSMHOLE` 或 `DK` | 打开**孔生成器窗口**（孔类型 2×2 + 子类型/大小/配合 + 盲孔/贯通 + 自动开关 + 实时剖面预览）；点「确定」后鼠标带图，点击放置 |
| AI / 脚本 | `OCSMHOLE [类型] [带螺纹\|无螺纹] [公制\|UN/UNC/UNF/UNEF\|G/BSPP\|R/BSPT\|NPT\|ACME\|矮牙\|Tr] [钻孔\|自定义\|间隙] [规格名 M10\|M10×1.25\|G1/8\|1/4-20\|NPT1/2\|Tr8×1.5\|ACME 1/4-16\|公称6.35 P1.058] [P1.5] [孔径8.5] [H18] [L15] [盲孔\|贯通] [全长] [6H\|6G\|精装配\|中等装配\|粗装配] [view 侧视图\|俯视图\|双视图] [at x,y] [rot 度]` | 一行直插（`at` 给了就落在该点） |

例：

```
OCSMHOLE 螺纹孔 M10 H18 L15 at 100,50          # M10×1.5 螺纹盲孔，孔深 18 / 螺纹有效长度 15
OCSMHOLE 简单孔 M10 钻孔 H20 贯通               # 攻 M10 的底孔 Ø8.5，贯通
OCSMHOLE 沉头孔 无螺纹 M10 间隙 中等装配 H22     # 沉孔 Ø18×11 + 通孔 Ø11
OCSMHOLE 埋头孔 带螺纹 M12 细牙 全长 H30         # 90° 埋孔 Ø24.4 + M12 细牙（底孔按粗牙默认）
OCSMHOLE 螺纹孔 带螺纹 G G1/8 H20 L12           # 规格名查表：G1/8（= `G 公称9.728 P0.907143`）
OCSMHOLE 螺纹孔 UNC 1/4-20 H18 L15              # `1/4-20` = `1/4-20 UNC`（省牙型后缀也收）
OCSMHOLE 螺纹孔 Tr Tr8x1.5 H20                  # ASCII 乘号 x = ×
OCSMHOLE 螺纹孔 NPT NPT1/2 H25 贯通             # `NPT 1/2` 同样收
OCSMHOLE 螺纹孔 ACME 1/4-16 H20                 # 一般 ACME；`矮牙 1/4-16` = Stub ACME
```

## 二、孔类型与参数（GUI 与命令行同一套）

**孔类型**（2×2 按钮）：`简单孔` / `螺纹孔` / `沉头孔` / `埋头孔`。
`螺纹` 不是孔类型的对立面：**沉头孔 / 埋头孔 可以选「带螺纹」或不带**（勾选「带螺纹」开关）。

| 孔类型 | 螺纹 | 底孔（被钻出的孔） | 附加 |
| --- | --- | --- | --- |
| 简单孔 | 恒无 | 子类型决定（见下） | — |
| 螺纹孔 | 恒有 | 小径 `D = d − 1.0825P`（GB/T 197） | 螺纹大径线 + 终止线 |
| 沉头孔 | 可选 | 带螺纹 = 底孔牙深表钻头；不带 = 子类型决定 | 圆柱沉孔 `d2 × t`（**GB/T 152.3-1988**；推荐值见下） |
| 埋头孔 | 可选 | 带螺纹 = 底孔牙深表钻头；不带 = 子类型决定 | 90° 沉锥 `d2`（**GB/T 152.2-2014**，适用 GB/T 70.3 等沉头螺钉；M1.6–M10） |

**沉头孔「推荐值」（自动）**：

* `GB/T 70.1 内六角圆柱头` → GB/T 152.3-1988 **表1**（官方 3.1：适用于 GB 70）；默认。
* `GB/T 70.2 内六角平圆头` → **标缺**：GB/T 152.3-1988 只有表1/表2（官方 3.2：表2 适用于
  GB 6190、GB 6191 及 GB 65），**没有 70.2 的沉孔表**；按「不插值」规则选中即明确报错。
* `GB 6190/6191/65 低圆柱头` → GB/T 152.3-1988 **表2**（额外可选项，数据有据）。

**埋头孔「推荐值」（自动）**：`GB/T 70.3` → **GB/T 152.2-2014**（沉头螺钉用沉孔，代替 1988 版）；
`d2` 取标准 `dc_max`（与 1988 版 d2 交叉一致），通孔取 `dh_min`（= GB/T 5277 中等装配），90° 几何。

**规格名（CLI 与 GUI 同一份表）**：CLI 的「大小」位置可以直接写 **GUI 下拉里的规格名**（表 `name`
是唯一事实来源）：`M10`、`M10×1.25`、`G1/8`、`R1/8`、`NPT1/2`、`1/4-20`（= `1/4-20 UNC`）、
`ACME 1/4-16`、`Tr8×1.5`…。归一容错：大小写、空格（`G 1/8`）、ASCII 乘号（`Tr8x1.5`）、
省牙型后缀（`1/4-20`）、省体系代号（体系已写时 `G 1/8`）。解析顺序 = **先按名查表 → 未命中回落
`公称 d P` 数值路径**（旧写法一律保留）；查表**不插值**：未命中报 `未知规格名 X` + 本体系示例；
写法属于别的体系（如 `G 1/4-20`）则点名「体系与规格不匹配：这是 UN 的规格」。

**子类型**：

* 带螺纹时：`标准螺纹`（粗牙，ISO 724）/ `细牙螺纹`（细牙列表，如 `M10×1.25`）。
* 不带螺纹时（简单孔、以及沉头/埋头的光孔版本）：
  * `钻头大小` —— 大小 = **标准麻花钻直径系列**（GB/T 6135.3-1996 直柄麻花钻，
    0.20–20.00，如 Ø5.1/5.2/6.7/6.8/8.5…）；沉头/埋头时另选「公称」（查沉孔表）。
  * `自定义` —— 大小仍选公称（沉头/埋头查沉孔表用），另填 **孔径**（mm）。
  * `螺栓间隙` —— 大小 = 螺栓公称 M；底孔 = **GB/T 5277** 通孔（此时 `配合` 才可选：
    `精装配` / `中等装配` / `粗装配`）。

**配合**：带螺纹 = 内螺纹公差带（M = `6H`/`6G`；UN = `2B`/`3B`；管螺纹/梯形无等级 → 置灰；本期只记录，不改变基本牙型几何）；
`螺栓间隙` = 精/中等/粗装配；其余子类型下**置灰**。

## 三、规则（用户定案）

> **两个量分开**（概念模型）：
> **① 螺纹有效长度**（= 噜合长度，内、外螺纹**同一个量**，“要旋进多深”）；
> **② 孔深 / 实际加工长度** = 有效长度 + **工艺余量**（刀具退出 + 不完整牙）。
> 界面上下两行各自可读、可改；自动值分别给出。

| 规则 | 实现 |
| --- | --- |
| **自动螺纹有效长度**：M（iso724）= `1.5 × 公称直径`（GB/T 3098.1-2010；M12 → 18）；UN/ACME/Tr 暂同 1.5d；**管螺纹 G/R/NPT = 表内 `eff_len`**（R = ISO 7-1 表第16栏（无退刀槽 = 最大基准距离+装配余量）；NPT = 基准距离基本+装配余量+基准平面偏差（偏差取 +1P 最大档，同族 NPTF LW3-55）；G = 同规格 R，ISO 228-1 无此口径、**待确认**） | `hole.rs::AUTO_THREAD_FACTOR`；`src/thread.rs::ThreadSpec.eff_len`；`螺纹有效长度` 勾「自动」且不勾「全长」时 |
| 螺纹孔的**底孔（钻孔）直径** = 底孔牙深表的实际钻头（M10×1.5 → Ø8.5；表外回退 GB/T 197 理论小径 d−1.0825P） | 「螺纹小径 D」读数仍是 d−1.0825P（M10 → 8.376），与钻孔分开显示 |
| **自动孔深** = 有效长度 + `2 × 螺距`（工艺余量：刀具退出；M10×1.5、有效 15 → **18**）。**锥管 R/NPT 的 2P 取锥管工艺口径“额外 1~2 牙”的上限，兼顾客锥不完整牙区** | `AUTO_RUNOUT_FACTOR = 2`；孔深自动 = 有效长度 + 2P；英制 P = 25.4/TPI |
| 不带螺纹（简单孔、沉头/埋头光孔）：**两个「自动」都不可选** | GUI 置灰 + 取消勾选；模型层给自动值直接报错 |
| 贯通孔：**孔深不能自动**（板厚/通孔长度必须手填） | 贯通无刀具退出问题；`孔深` 手填 |
| **贯通 = 无 118° 底锥** | `range=through` 时 `cone_height=0`，侧视不画两条锥斜线 |
| **盲孔底锥 118°**（半角 59°，锥高 = R小径 / tan 59°） | `CONE_HALF_ANGLE_DEG = 59` |
| 螺纹大径 `D1 = d`、小径 `D = d − 1.0825P`（GB/T 197；M10×1.5 → **8.376**） | 几何与读数同源 |
| 「全长」：`L = H`，此时孔深必须手填（循环依赖） | `full_thread`；不画螺纹终止线 |

沉头/埋头时 `孔深 / 螺纹有效长度` **从沉孔底 / 埋头锥底起算**（螺纹与底孔都在沉孔以下）。

> ⚠️ 管螺纹的**孔深起算面 = 孔口/端面**（材料表面）；R 页注“螺纹始端倒角轴向 ≤1 牙、倒角含在有效长度内”
> —— 倒角区算在有效长度内，不额外加长。

## 四、画法与图层（GB/T 4459.1 简化画法）

* **侧视（剖）**：
  * 底孔壁（小径 = 底孔径）→ `1轮廓实线层` 粗实线；盲孔 118° 底锥同层；
  * 螺纹大径线（细实线）→ `2细线层`，从沉孔底/孔口画到螺纹终止处；
    **螺纹终止线** → `1轮廓实线层`（连接两条大径细线；全长/到底不画）；
  * 沉孔壁 + 环形底面、埋头 90° 锥线 → `1轮廓实线层`；
  * 轴线 → `3中心线层`，两端各伸 3 mm。
* **俯视（端视）**：
  * 底孔小径整圆粗实线；螺纹孔再加大径细实线 **3/4 圈**
    （照 `partgen_more.rs` 螺母端视：`270° → 180°`，`2细线层`）；
  * 沉孔/埋头再加深/浅一圈实线圆；
  * 十字中心线 → `3中心线层`。
* **不生成尺寸标注**（`D1`/`D` 只在窗口预览示意图里画）。
* 俯视图（若同时勾选）放在侧视图右侧、间隙 20 mm。

## 六、坑 / 约定

* **沉头/埋头的底孔与螺纹**：带螺纹的沉头/埋头 = 沉孔 + 内螺纹；底孔（钻孔）取
  底孔牙深表的钻头（表外回退 `d−1.0825P`），不是用 GB/T 152.3/152.2 表里的 `d1`
  （那是**光孔沉头**配套的间隙孔）。
* **埋头几何按 90° 锥**：锥深 = (d2 − 底孔径)/2；表里的 `t≈` 是名义深度（界面显示用）。
* **表外规格报错**（不插值、不外推）：如沉头孔没有 M7、埋头孔没有 M24；螺栓间隙从 M1 到 M150。
* **沉头孔标准口径**：推荐值默认 GB/T 152.3 表1（GB 70 → 70.1）；表2（GB 6190/6191/65）
  可切换；**GB/T 70.2 无官方沉孔表（标缺，不插值）**；GB/T 152.4 六角头用沉孔未纳入。
* **埋头孔**：GB/T 152.2-2014 只到 M10；M12 及以上明确报错（不插值）。
* 命令前缀三处同步：`plugin.toml` 的 `command_prefixes`、`lib.rs` 的 `MANIFEST.command_prefixes`
  与短命令分发、`guide_server::COMMAND_CATALOG`；`ribbon_registers_*` 测试断言两处前缀**多重集相等**。
