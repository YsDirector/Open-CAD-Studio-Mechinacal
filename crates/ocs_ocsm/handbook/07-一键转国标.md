# 07 一键转国标 `D2G`（`OCSMDIM2GB`）

> 拿到的图/别人画的标注是"原生标注"（默认样式），用一条命令把它们**整体换成 OCSM 的国标样式**。

## 一、用法

```
命令：D2G        （= OCSMDIM2GB）
```

行为：

1. **扫描范围**：有选中标注 → 只转选中的；没选中 → 扫**模型空间**里的全部原生标注。
   （选中“圆”或“圆心标记”的任一个，都能带上那个圆的智能圆心标记。）
2. **判定**：已经是 OCSM 生成的（带 `OCSM_EDIT` 记录）会跳过；不能转的会说明原因。
3. **转换**：
   - 幂等补齐基建（图层 / 文字样式 `OCSM_GB` / 需要的标注样式——即使这张图从没跑过 `OCSM` 初始化）；
   - 为每条标注建**匿名块**（`INSERT` 引用它）——尺寸文字/箭头按国标画法重画；
   - **智能圆心标记**（功能区 Center Mark 那个）→ 换成 `3中心线层` 的**两条十字中心线**，
     长度 = **直径 + 图框比例×6**（与 `ZX` 完全一致），并删掉原来那个隐形载波线；
     半径来自标记自带的关联记录，**不用猜**。
     （老式 `DIMCENTER` 画出来的两条散十字**不转** —— 它不存半径，且与手画十字无法区分，
     需要就直接 `ZX` 点那个圆。）
   - 加新实体 → **删原标注**；
   - 新标注带 `OCSM_EDIT`（参数 + 引导几何）→ 之后可以用 `ME` 继续编辑（中心线是普通 `LINE`，直接改）。
4. **一个撤销条目**：`OCSMDIM2GB 原生标注转 GB`。

输出示例：`OCSMDIM2GB：…`（报告里给出 seen/converted/skipped 统计与跳过原因）。
没找到可转标注时：`OCSMDIM2GB：未找到可转换的原生标注（仅扫描模型空间）`。

## 二、什么时候用

| 场景 | 用 D2G？ |
| --- | --- |
| 客户/上游给的图，尺寸是普通标注，要统一成你们的样式 | ✅ |
| 图上有宿主的**智能圆心标记**（功能区 Center Mark），想要国标中心线 | ✅ 一并转（`直径 + n×6`，落 `3中心线层`） |
| 图上有老式 `DIMCENTER` 的散十字 | ❌ 不转（不存半径）——直接 `ZX` 点那个圆更快 |
| 自己用宿主原生 `DIMLINEAR` 标的，想变国标画法 | ✅ |
| 标注已经是 OCSM 生成的（`ME` 能打开） | ❌ 不需要（用 `ME` 改） |
| 标注在**布局/图纸空间** | ⚠️ 不支持（只扫模型空间） |

## 三、AI 侧配方

```jsonc
// 1) 看有哪些标注
{ "op": "read", "op": "query", "parameters": { "type": "Dimension" } }
// 2) 转换（全部或先选中若干句柄再转）
{ "op": "execute", "request": { "op": "run", "request_id": "d2g1", "document_id": 1, "revision": 30, "cmd": "D2G" } }
// 3) 读报告 + 核对
{ "op": "read", "op": "history" }
{ "op": "read", "op": "query", "parameters": { "type": "Insert" } }   // 匿名块 INSERT
```

## 四、坑

1. **只扫模型空间**：图纸空间里的标注不动（把标注放模型空间，或用宿主命令先移到模型空间）。
2. **转换是"删旧建新"**：若在标注上挂了别的信息（自定义扩展数据），转换后不保留。
3. **尺寸值语义**：转换按原标注的测量值/文字重建；如果原标注是**手动改过文字**的（如写死 "10"），
   转换后仍按测量值重画 → 转换前记下那些特例，转换后逐条用 `ME` 修正。
4. **换比例出图**：转完若换图框比例，标注样式要跟着换（新图框会建 `OCSM_GB_xN`）。

## 五、验证清单

- [ ] 日志报告 converted 数 = 你预期要转的条数。
- [ ] 图上标注样式为 `OCSM_GB*`，图层 `7标注层`。
- [ ] 随机挑一条选中 → `ME` 能打开配置窗口（说明带 `OCSM_EDIT`）。
- [ ] 一次 `undo` 能整体退回转换前（含被删的原标注）。
