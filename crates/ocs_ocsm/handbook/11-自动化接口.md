# 11 自动化接口（AI / 脚本驱动 OCS）

> **AI 侧必读**。三种入口：宿主原生 MCP、插件 MCP、插件本地 HTTP。

## 一、三个入口

| 入口 | 启动 | 用什么 |
| --- | --- | --- |
| **宿主原生 MCP** | 启动 OCS 时带 `--mcp`（命令行旁会出现 MCP 徽章） | 工具：`ocs_sessions` / `ocs_read` / `ocs_execute` / `ocs_capture` |
| **本机浏览器控制桥** | 宿主跑自动化服务时 | 描述符 `~/.config/OpenCADStudio/automation/<session_id>.json`（0600，含 port/token）→ 直接 TCP/HTTP 调 |
| **插件 MCP / HTTP** | OCS 里跑 `OCSMMCP`（打印接入信息） | 插件 MCP：标准件等插件能力；插件 HTTP：`http://127.0.0.1:23751`（端口从 23751 起试，最多 +16） |

> 三者可以混用：**宿主接口管"图纸"**（读状态/跑命令/截图），**插件接口管"插件专属能力"**（零件库、螺栓副、标注窗口的 HTTP API）。

## 二、宿主 MCP 四个工具

### `ocs_sessions`
列出/开启会话。返回 `session_id`（后续所有调用都要它）。
`{"launch_if_none": false}` 表示没有会话时不新开一个。

### `ocs_read`（只读）
`op` 取值（常用）：

| op | 用途 |
| --- | --- |
| `state` | **每轮操作前必调**：`document_id`、`revision`、当前图层、选择集规模… |
| `query` | 查实体/记录：`type`、`layer`、`bounds`、`near`、`contains_point`、`handle(s)`、`detail`（summary/geometry/full）。注：**会把块定义里的成员也列出来**（例：插入图框后会看到一堆 1:1 坐标的 `1轮廓实线层`/`2细线层` 线 —— 那是块定义内容，不是图上副本；插入体本身是那个 `Insert`） |
| `history` | **命令行日志**（含插件 `push_output` 的报告行与"撤销：xxx"） |
| `events` | 事件流（含 `kind:"selection"` 的**高亮变化**、`selection_revision`） |
| `commands` | 命令清单（含插件命令；可按 `search` 过滤） |
| `records` | 记录/扩展数据（含 `OCSM_PART`、`OCSM_EDIT`、超链接…） |

### `ocs_execute`（改图）
`request` 的 `op`：

| op | 说明 |
| --- | --- |
| `run` | 跑命令（**插件命令也走这里**）：`{"op":"run","request_id":"…","document_id":N,"revision":R,"cmd":"OCSMJOINT at …"}` |
| ↑ 图框直插 | `cmd:"TF a3_landscape 1:2 at 0,0"` —— **不用点选择窗口**（`TF` 带参数 = 直插，见 `02`）；不带参数才弹窗 |
| ↑ 实体当答案 | `cmd:"ZX 62"`（十六进制句柄）—— 插件要把非关键字 token 交回宿主（`on_text_input → Ignored`），宿主才按句柄喂进拾取步骤 |
| `cancel` | 取消当前交互命令（等于 Esc）；**发下一条命令前建议先 cancel** |
| `undo` | 撤销一步（等价 Ctrl+Z） |
| `new` / `open` / `save` | 新建/打开/保存文档 |

要点：
- **`request_id` 必须唯一**；重复用会报 `Request payload changed`（见 `12`）。
- `revision` 过期会报错 → 用 `state` 的最新值。
- 命令返回值可能是"提交受理"，**真正的结果看 `history` 日志**（插件的报告都写在日志里）。

### `ocs_capture`
`scope: viewport|window`、`max_dimension`。**每做完一步都截图核对**，别只看返回 ok。

### 交互命令（`start` + `input`）——必须**同一个 MCP 会话**

宿主对 `input` 有所有权门：命令活跃时只有 `control.owner == Some((tab, client_id))` 才放行，
而 MCP 服务器给**每个客户端实例**随机 `client_id`（`src/mcp.rs:326`）。
所以「一次调用一个新连接」的方式（如 `mcporter call ...`）驱动 `input` 永远返回
`command_busy` —— 要用**一个长连接**：仓库里 `tools/ocs_session.py` 就是这个（实测可用）：

```bash
python3 tools/ocs_session.py <<'EOF'
run CENTERMARK
input entity DD 315,350,0      # 实体拾取：句柄 + 拾取点
cancel                         # 结束该交互命令
run D2G
query line 3中心线层
EOF
```

* 插件命令另有一条捷径：只要它在 `on_text_input` 里返回 `CommandStep::Ignored`，
  就可以把**十六进制句柄当命令答案**一次发过去：`{"op":"run","cmd":"ZX 62"}`。
* 宿主自带命令（`CENTERMARK`/`DIMCENTER`/`DIMLINEAR`…）不吃这种答案，必须走 `start`+`input`。

## 三、插件 HTTP（脚本/窗口共用）

| 端点 | 作用 |
| --- | --- |
| `GET /api/parts` | 零件目录（族/kind/规格/长度系列/视图） |
| `GET /api/part_svg?family&d&l&view` | 单件预览 SVG（结构要素无 `l`：磨外圆带 `&b1=`，退刀槽带 `&P=1.5&g1=…`） |
| `POST /api/part_pick` | 参数化插单件（JSON：family/d/l/view/x/y/rotation；结构要素可再带 `"params":{"P":1.5}`） |
| `POST /api/part_export` | "出库"：建块 + 登记待放置件（人类窗口按钮用） |
| `POST /api/joint` | **装配螺栓副**（件链 JSON，见 `04`） |
| `POST /api/joint_plan` | 只算不写：返回 SVG 预览 + 报告 + 数字 |
| `POST /api/joint_place` | 建预览块 + 登记待放置件链（人类窗口按钮用） |
| `GET /gear` | **齿轮窗口**（参数表 + 视图按钮 + 实时预览；外/内齿轮可切；`OCSMGEAR` 不带参数时打开） |
| `GET /api/gear_svg?m&z&h&ha&c&beta&x&view&n` | 齿轮当前视图预览 SVG（`view`=`section`/`side`/`simplified`/`front`；`beta` 单位度，右旋为正；`n` 图框比例） |
| `GET /api/gear_info?…`（同上参数） | 齿轮派生尺寸 + 提示（d/da/df/db/ρ/倒角 C/齿距角/齿顶半齿角/notes） |
| `POST /api/gear_export` | 齿轮「生成到图纸」：建块 + 登记待放置件（人类窗口按钮用；同样使 `OCSMGEAR`）。body 是 JSON，可带 `"kind":"internal"` 出内齿轮。**未跑过 `OCSM` 会返回 400 + 拦截原因** |
| `POST /api/gear_insert`（命令行） | AI 一行直插：`run "OCSMGEAR 2 40 20 view front at 300,200 rot 0"` |
| `GET /shaft` | **轴生成器窗口**（段表 ↔ 行文本双向同步 + 实时预览；`OCSMSHAFT` 不带参数时打开） |
| `GET/POST /api/shaft_parse` | DSL/JSON → 归一化段模型（GUI 行文本→段表回填用；错误带「第 N 行/段 + 原因」）。POST body 为 `{"dsl":"…"}` 或 JSON 模型/行 DSL；GET 用 `?dsl=` |
| `GET/POST /api/shaft_preview` | 轴侧视图预览 SVG（参数同上；不碰图纸） |
| `POST /api/shaft_export` | 轴「生成到图纸」：body = JSON 模型（+ 可选 `at`/`rot` + `tab`）。无 `at` = 建块 + 登记待放置件（人类窗口按钮用）；有 `at` = 直接插入。**未跑过 `OCSM` 会返回 400 + 拦截原因** |
| `GET /hole` | **孔生成器窗口**（简单/螺纹/沉头/埋头 + 盲孔/贯通 + 自动开关 + 实时剖面预览；`OCSMHOLE`/`DK` 不带参数时打开） |
| `GET /api/hole_sizes` | 孔生成器四套数据表（ISO 724 粗/细牙、钻头底孔径、GB/T 152.3 沉头、GB/T 152.2 埋头、GB/T 5277 间隙），带 `source`/`note` |
| `POST /api/hole_preview` | 孔模型 JSON → `{ok, svg, values}`（预览 + 派生数值；不碰图纸） |
| `POST /api/hole_export` | 孔「确定」：body = JSON 模型（+ 可选 `at`/`rot` + `tab`）。无 `at` = 建块 + 登记待放置件；有 `at` = 直接插入。**未跑过 `OCSM` 会返回 400 + 拦截原因** |
| `GET /api/guide?handle=` / `POST /api/apply` / `POST /api/apply_refresh` | 引导线标注的读参数/写超链接/生成标注 |
| `POST /api/rough_apply` | 粗糙度符号生成 |
| `GET /guide.html?handle=` `GET /parts` `GET /joint` `GET /gear` `GET /shaft` `GET /hole` `GET /rough.html` | 各配置窗口页面 |
| `GET /api/page_ping?p=<页面>` | 窗口心跳（避免重复开窗） |

## 四、硬规矩（踩过的坑换来的）

1. **动图前重读 `state`**：`document_id`/`revision` 每次都可能变（新开文档、别人改图、
   宿主重启后文档丢失）。**禁止硬编码**。
2. **一次事务 = 一个撤销条目**：插件的批量写图命令自己 `BeginUndo`/`CommitUndo`；
   脚本自己连续发多条 `run` 时，是多个撤销条目。
3. **交互命令会"吃掉"后续输入**：处于放置/拾取态时，你发的下一条 `run` 会被当成点/参数。
   发新命令前先 `op:"cancel"`。
4. **高亮（选区）会变**：用 `events` 的 `selection_revision` 判断是否需要重读选区；不要缓存句柄集太久。
5. **命令名大小写不敏感，参数原样转发**；插件的报告（`OCSMJOINT：…`）在 `history` 里，不在返回值里。
6. **无头模式（`--serve`）**：`open` / `run <命令 + 内联坐标>` / `save` 一问一答稳；
   `--export` 只支持 `.dwg`/`.dxf`（不支持 png/pdf）→ 要出图用其它渲染路径（见 `12`）。
7. **插件热重载/重启后**：文档会丢、`document_id` 变、GUI 窗口心跳仍在（旧页面还活着）→
   先关旧窗口再开新窗口。

## 五、最小可跑的一轮（复制即用）

```bash
MC=/home/ysdirector/.local/bin/mcporter
S=$($MC call ocs.ocs_sessions --args '{"launch_if_none":false}' --output json | python3 -c 'import json,sys;print(json.load(sys.stdin)["result"][0]["session_id"])')
$MC call ocs.ocs_read  --args "{\"ocs_session_id\":\"$S\",\"op\":\"state\"}" --output json     # 拿 document_id/revision
$MC call ocs.ocs_execute --args "{\"ocs_session_id\":\"$S\",\"request\":{\"op\":\"run\",\"request_id\":\"r1\",\"document_id\":1,\"revision\":9,\"cmd\":\"OCSM\"}}" --output json
$MC call ocs.ocs_read  --args "{\"ocs_session_id\":\"$S\",\"op\":\"history\"}" --output json    # 看插件报告
$MC call ocs.ocs_capture --args "{\"ocs_session_id\":\"$S\",\"scope\":\"viewport\"}" --save-images /tmp/ocs --output json
```

## 六、验证清单
