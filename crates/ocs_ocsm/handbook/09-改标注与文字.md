# 09 改标注与文字（`ME` / `OCSMEDIT`）

> OCSM 生成的标注/符号是**参数化产物**：改参数 → 重生成，别手动拖。

## 一、`ME`（`OCSMEDIT`）

```
1) 选中一个 OCSM 生成的标注（尺寸/焊接/引线/公差/向视/粗糙度…）
2) ME            （= OCSMEDIT）→ 打开**同一个**标注配置窗口
3) 窗口从 /api/guide 读该标注的 OCSM_EDIT 记录 → 恢复全部参数（文字/样式/偏移/类型…）
4) 改完点「应用并刷新」→ 插件**删旧标注、用原引导几何重新生成**（替换，不叠加）
```

- 没选标注时：`OCSM: 请先选中一个 OCSM 生成的标注（引导生成的尺寸/焊接/引线/公差等），再执行 OCSMEDIT。`
- 记录里没有 `OCSM_EDIT`（例如原生标注，或标准件）→ 该命令不适用（先用 `D2G` 转成 OCSM 标注）。

## 二、文字

| 需求 | 做法 |
| --- | --- |
| 技术要求/说明文字 | 在 `6文字层` 用宿主 `MTEXT`/`TEXT`，样式选 `OCSM_GB` |
| 标注文字 | **不要手改标注文字**；在配置窗口改（改完"应用并刷新"） |
| 标注文字外移 | 拖动文字后尺寸线自动延伸（已实现），或在窗口里调偏移 |
| 字体不一致 | 统一用 `OCSM_GB`；混合字体会退化成替代字体（如 Latin 用 simplex） |

## 三、AI 侧配方

```jsonc
// 1) 找到要改的标注（句柄）
{ "op": "read", "op": "query", "parameters": { "type": "Dimension", "layer": "7标注层" } }
// 2) 选中它并打开配置窗口
{ "op": "run", "request_id": "m1", "document_id": 1, "revision": 50, "cmd": "SELECT 3F" }   // 选择集
{ "op": "run", "request_id": "m2", "document_id": 1, "revision": 50, "cmd": "ME" }
// 3) 读它的记录（参数 + 引导几何）
GET http://127.0.0.1:23751/api/guide?handle=0x3F
// 4) 改参数并重生成（等价于窗口里"应用并刷新"）
POST /api/apply_refresh  { "handle": "0x3F", "type": "DIAMETER", "text": "⌀30H7", … }
// 5) 核对：旧标注已删、新标注句柄不同
{ "op": "read", "op": "query", "parameters": { "type": "Dimension" } }
```

## 四、坑

1. **"应用并刷新"= 删旧建新** → 标注句柄会变；如果你在别处引用了旧句柄（脚本、超链接），要重取。
2. **不要手动编辑生成的标注几何**（拖箭头、改文字）：下次刷新就恢复原状；要改就改参数。
3. **引导线必须还在**：`ME` 靠"原引导几何"重生成 → 删了引导线就只能重新画。
4. **同一引导线可以反复刷新**（引导线带 URL，是"意图"的持久载体）。
5. 命令里**不能用 sender 通道**（会与主线程死锁）——这条是插件实现约束，使用者不用管，但如果你在写插件要记得。

## 五、验证清单

- [ ] `ME` 打开的窗口里参数 = 图上标注的实际值（说明记录读到了）。
- [ ] 应用并刷新后，图上只有一条该标注（没有叠加）。
