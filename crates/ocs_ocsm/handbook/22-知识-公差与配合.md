# 22 知识：公差与配合（骨架）

> 选配合、查偏差、写进标注。插件内置 **ISO 286** 的 4 张表（孔/轴 × 常用公差带），配置窗口里选代号即可。

## 一、基本概念

| 术语 | 含义 |
| --- | --- |
| 基本尺寸 | 设计尺寸（如 Ø30） |
| 极限尺寸 | 上极限 / 下极限（允许的最大/最小） |
| 偏差 | 上偏差 ES/es、下偏差 EI/ei（孔用大写、轴用小写） |
| 公差 | 上偏差 − 下偏差（只与公差等级有关） |
| 基本偏差 | 靠近零线的那个偏差（代号决定，如 `H` 下偏差=0、`h` 上偏差=0） |
| 公差等级 | IT01…IT18，数字越大越松（配合尺寸常用 IT6–IT9） |
| 配合 | 间隙配合（H/g、H/f…）、过渡（H/js、H/k）、过盈（H/p、H/s…） |

**基孔制优先**：`H` + 轴的基本偏差（`H7/k6`）。基轴制用于冷拉圆钢/标准件（`K7/h6`）。

## 二、常用配合（速查）

| 配合 | 代号 | 典型场合 |
| --- | --- | --- |
| 间隙（易装） | `H7/g6`、`H8/f7` | 滑动/需相对运动、定位销 |
| 过渡（可拆、定位准） | `H7/k6`、`H7/js6` | 轴承内圈与轴、齿轮与轴（加键） |
| 过盈（不拆） | `H7/p6`、`H7/s6` | 压入配合、销 |
| 基孔制定位孔 | `H7`（配标准件） | 螺栓通孔一般 `H12/H13`（粗装配） |

## 三、几何公差（GB/T 1182）

- 14 个特征符号（直线度、平面度、圆度、圆柱度、平行度、垂直度、倾斜度、位置度、同轴度、对称度、
  圆跳动、全跳动、线轮廓度、面轮廓度）+ 附加符号（⌀ 公差带、Ⓕ 最大实体、Ⓜ 可逆…）。
- 标注：框（符号 | 公差值 | 基准） + 指引线；基准用基准符号（A/B/C）。
- 用法要点：位置度通常带 ⌀（圆形公差带）；同轴度可被"圆跳动"替代（更易测量）；基准要选功能面。

## 四、表面粗糙度（GB/T 131）

| Ra 值（µm） | 典型工艺 |
| --- | --- |
| 12.5 / 6.3 | 粗车、钻孔 |
| 3.2 | 精车、铣 |
| 1.6 | 精磨、拉削 |
| 0.8 / 0.4 | 精磨、研磨、抛光 |
| 0.2 以下 | 镜面（研磨/超精加工） |

- 未注粗糙度用"其余 ⌀"标注在图纸右上或技术要求里（例：其余 6.3）。
- 配合面、密封面、滑动面必须单独注（且与配合精度匹配：IT7 面 ≈ Ra1.6，IT6 ≈ 0.8）。

## 五、OCSM 里的做法

- 在标注配置窗口里选 **TOLERANCE**：代号模式（`⌀30H7`）或极限偏差模式（`⌀30 +0.021/0`）；
  插件按 ISO 286 表算出偏差，用**匿名块 + MTEXT 堆叠**画出。
- **GD&T** / **DATUM** 在同一个窗口里（形位公差框 / 基准符号，两种国标画法）。
- 粗糙度：`CC`（`OCSMRGH`）交互点选插入点 → 窗口填形态与数值。
