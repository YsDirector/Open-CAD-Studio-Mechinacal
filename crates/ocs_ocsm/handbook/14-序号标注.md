# 14 序号标注（`BALLOON`，GDIM 里选「序号」）

> 序号标注是**引线标注的变体**：把零件序号引到装配图上，并与明细表的「序号」列挂钩。
> 它和引线同构（两段 PLINE 引导），但**可以横向或纵向扩展**：一个"组"里放多个序号。

## 一、一个组长什么样（几何契约）

```
一个组 = 1 条指引线 + 1 个圆点 + N 条横线 + N 个序号（各自写在自己横线上方居中）
                    │
                    └── 横线之间按扩展方向连接：
                        横向 = 共线并排，相邻之间 V 形折线
                        纵向 = 上下叠放，在指引线那一端用竖线连接
```

引导几何（`10引导线层` 上的**两段 PLINE，3 顶点**，与引线完全相同）：

| 顶点 | 含义 | 生成物 |
| --- | --- | --- |
| 顶点1（起） | **指针点** | 画 **圆点**（Ø0.33h，实心）——不是箭头 |
| 顶点2（拐） | **拐点** | 块原点；横线的**指引线那一端** |
| 顶点3（末） | 肩线末端 | **只定方向**（横线自拐点朝它延伸）与"往哪边长" |

> **横线必须水平**（第二段画成水平）。画成竖直 → 报错：
> `序号标注：横线必须水平（第二段水平画）——不支持竖肩线（序号不旋转）`。
> 序号**永远水平书写**（用户定案：不要"竖肩线 + 序号旋转 90°"那种样式）。

### 比例（照参考图实测，基准 = 字高 h，默认 3.5 mm，随图幅倍率缩放）

| 量 | 取值 | 说明 |
| --- | --- | --- |
| 横线长 | 文字宽 + **1.0h**（两侧各 0.5h） | 单字符 ≈1.4h、双字符 ≈1.8h |
| 数字位置 | 横线**中点上方 0.3h** | 居中（`BottomCenter` 锚定） |
| 横向间隙 | **0.5h** | 两条横线之间 |
| V 形折线 | 宽 0.5h、**深 0.38h**（朝文字下方折） | 表示"同一指引线的续接" |
| 纵向节距 | **1.6h** | 上下两条横线的距离 |
| 圆点 | **Ø0.33h**（八边形实心） | 两枚 `SOLID`（宿主不画填充圆） |

## 二、两种扩展方向

| `dir` | 排布 | 连接符号 | 典型用法 |
| --- | --- | --- | --- |
| `H` 横向（默认） | 横线**共线**并排，从指引线那端朝肩线末端排 | V 形折线 | 一条横线上排 2、3 两个序号 |
| `V` 纵向 | 横线**上下叠放**（节距 1.6h），都在指引线那端对齐 | 竖线（在指引线那一端） | 6/5、14/13 这种上下两行 |

- **条目顺序 = 从指引线向外/向上**：`items=5,6` → 5 贴指引线、6 压在它上面（与图上 6 在上、5 在下一致）。
- 每组只有**一条指引线 + 一个圆点**（共用指针）：典型场景是螺栓副（螺栓/垫圈/螺母）写一组共引。

## 三、序号与编号规则（用户 2026-09-15 定案）

1. **结尾必须是数字**：`7`、`A1`、`M10`；`A`、`A1B` 都不算序号（会报错/不收）。
2. **默认取号 = 图纸已有最大序号 +1**，前缀与位宽保留：`A1`→`A2`、`A09`→`A10`、`9`→`10`。
   - "已有" = ①②已生成的序号球标（`OCSM_BALLOON` 台账）+ ②明细表行块的「序号」属性。
3. **明细表按序号升序排列**（`A2` < `A10`，纯数字排最前）；每加一个新序号，明细表跟着加一格。
4. **手动填的序号与已有重复**时，看窗口里的「**插入序号**」开关：
   - **勾选** → 把插入序号**之后的**所有序号全部 +1（插队后移）；
   - **不勾选** → 视为同一零件，明细表里**该序号行数量 +1**（合并计量）。

## 四、怎么用（人类侧）

```
1) 10引导线层 画两段 PLINE：指针点 → 拐点 → 肩线末端（第二段画水平）
2) 选中它 → GDIM → 类型选「序号」
3) 面板里填条目：+ 添加 / 自动取号（上一个 +1）/ ▲▼ 调序 / ✕ 删
   选扩展方向（横向/纵向）；需要插队时勾「插入序号」
4) 看预览（与服务端同一套比例）→「应用并刷新」→ 生成在 8符号标注层（匿名块 *XH + INSERT）
   引导 PLINE 保留（不打印），以后选中标注 → ME 可再改
```

- 落点吸附：**指针点落在零件块内** → 关联该零件（读 `XDATA OCSM_PART`），台账里记下；
  不在任何零件块内就按画的点走。多层套块时取**界盒最小**的那个（不会误挂到大装配块）。
- 生成物台账 `OCSM_BALLOON`（JSON）：序号列表 / 方向 / 插入模式 / 关联零件 —— 明细表联动与重排靠它。

## 五、AI 侧配方

```jsonc
// 1) 画引导线（10引导线层，两段 PLINE；第二段必须水平）
{ "op": "run", "cmd": "10" }
{ "op": "run", "cmd": "PLINE 20,10 45,35 70,35" }
// 2) 直接按参数生成（等价于人在窗口里点「应用并刷新」）
//    POST /api/apply_refresh {"handle":"6F","url":"http://127.0.0.1:23751/DIM/BALLOON/0?items=2,3&dir=H"}
// 3) 核对：8符号标注层 的 INSERT（块名 *XH{n}）+ 台账
```

- URL 键：`items=2,3`（逗号分隔，从指引线向外/向上）、`dir=H|V`、`ins=1`（冲突时插入后移）。
- `GET /api/guide?handle=…` 返回里带 `balloon{items,dir,ins}` 与 `balloon_next{existing,next}`（自动取号用）。

## 六、坑

1. **横线必须水平**：竖肩线直接报错（这是定案，不是缺功能）。
2. **指针点是圆点不是箭头**：别按引线那套找箭头。
3. **条目顺序**：`items` 是"从指引线向外/向上"，不是从上到下。
4. **一个组只有一个圆点**：想各自引到不同零件，就画两个组（或用两条引导线）。
5. 序号取号依赖图纸上"已有"的球标/明细表行 —— 全新图上第一次取号 = `1`。
6. 生成物是**匿名块**（`*XH{n}`）；改参数走 `ME`（删旧重建），不要手改块内文字。

## 七、明细表联动（已实现）

生成/改号球标后**自动同步明细表**（也可随时用命令 `BOMSYNC` 手动重排）：

| 规则 | 实现 |
| --- | --- |
| 表**按序号升序**、自下而上 | 行序 = 序号升序（`A2` < `A10`；纯数字排最前） |
| 每加一个**新序号**，表跟着**加一格** | 球标每个条目一行；关联不到零件的条目建**空行**（只写序号，待手填） |
| 序号重复 → 勾「插入序号」：其后全部 **+1** | 已有的受影响的球标**整体重编号**（重建块，几何/台账一起更新）+ 表跟着重排 |
| 序号重复 → 不勾：该序号**数量 +1** | 同一序号被 N 个球标引用 → 该行 数量 = max(聚合件数, 引用次数)，总重 = 单重 × 数量 |
| 没被球标引用的零件 | 沿用**旧表里同 (图号, 名称) 的序号**；旧表里没有 → 自动接号（最大序号 +1） |
| **手改保护** | 序号永不锁；**数量**可锁（`BOMLOCK 5 3` / `BOMLOCK 5 off`）；其余列**非空即保留**（空白才填新值）。删行 = 重置 |

- 行内容来自零件台账 `OCSM_PART`：图号 = 代号、名称 = 名称 + 规格、材料、单重；总重自动算。
- 前置条件：能关联到零件的只有**指针点所在的那个零件**（组的第一个条目）——用户定：只靠吸附。
- 表模板（`bom/OCSM_BOMROW.dwg`）缺失时：球标照常生成，只在报告里给 warning（不挡主流程）。

> 未存盘的图：xlsx 会落到**临时目录**（`/tmp/OCSM/`，Windows `%TEMP%\OCSM\`）——会被系统清理，长期保存请先存盘。

## 八、检查清单

- [ ] 横线是水平的、序号在横线上方居中、圆点在指针点处；
- [ ] 横向扩展的 V 形折线、纵向扩展的竖线都在"远离指针/贴指引线"的正确一侧；
- [ ] 序号与明细表**一致**（`BOMSYNC` 后可逐行对数：序号/图号/名称/数量/总重）；
- [ ] 指针点在零件块内（台账能关联上），否则明细表只会出现空行。
