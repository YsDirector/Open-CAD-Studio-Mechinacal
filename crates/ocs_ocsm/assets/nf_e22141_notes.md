## 公式（中文译本 p04/p05/p07；源码里均为权威）

| 项 | 公式 | 出处 |
|---|---|---|
| 公称直径 | `A`（名义尺寸，与滚动轴承内径系列相同；**主参数**） | p07 |
| 基准直径关系 | **`A = m(N + 2x + 0.4)`** → `x = (A − m(N+0.4))/(2m)` | p07 |
| 分度圆 / 基圆 | `d = N·m`；`db = d·cos20°` | p07 |
| 外花键齿顶圆（大径） | 外径定心 `A₁′ = A`；齿面定心 `A₂′ = A − 0.2m` | p04/p07 |
| 外花键齿根圆（小径） | 平齿根 `B = A − 2.4m`；圆齿根 `B₁ = A − 2.694m` | p07/p05 |
| 内花键齿根圆（大径） | 外径定心 `A₁″ = A`；拉削+齿面定心 `A₂″ = A + 0.3m` | p04/p07（p18 表头按 m 印 A+0.15…A+3） |
| 内花键齿顶圆（小径） | **`D = A − 2m`**（任何情况） | p04/p07、p18 D 列 |
| 圆角 / 倒角 | `R = 0.3m`、`Ri = 0.528m`、`h = 0.1·max(m,1)` | 源表校验列 |

引擎换算（`InvolParams`）：`d_eff = d + 2x·m = A − 0.4m`；
`ha* = 0.2`（→ `da = A`）、`hf* = 1.0`（平）/ `1.147`（圆）、`rho* = 0.3 / 0.528`；
内花键 `internal_major_dia() = A`、`internal_minor_dia() = A − 2m`。
**注意**：NF 不是 DIN —— 不要套 DIN 的 `d_B = d+1.1m+2xm` / `ha*=0.45` / `x∈[−0.05,0.45]`。

## 引擎接口（`crates/ocs_ocsm/src/invol_spline.rs`）

- `SplineStd::NF` 走独立分支：`A` 是主参数（第 3 参 `d_b` 槽位；CLI `A…` / `a=`）。
- `nf_e22141_rows()` / `nf_e22141_modules()`：入库表与 10 个模数档。
- `lookup_by_a(a, m?)`：命中可多行（多 N 变体 / 不给 m 时多 m）；未命中列附近候选；
  p18 与后三页同 `(m,A,N)` 重复行去重保留信息全的行。
- `nf_check_rows()` / `nf_check_tables()`：检查表全量与 `(page, table_no)` 统计
  （399 行 / 10 张表；CSV 注释与表头在解析时跳过）。
- `nf_check_by_a_m(a, m)` / `nf_check_by_a_n(a, n)`：按 `(A,m)` 或 `(A,N)` 取该档检查
  尺寸/公差/配合行（p29 的 A 是直径范围 → 区间包含；p31–p35 的 m 由 `section` 解出）。
- `build_report` 第 4 节对 NF 输出：检查尺寸（K/E/U/F/F1/V/V1/G/G1 + p27 q1..q7）、
  p26 设计尺寸、p29/p31–p35 偏差行（微米，上/下）与页码/表名/source；表外档明确报“没有该档”。
- `x_from_a(a,m,z)` / `a_from_x(m,z,x)`：p07 公式。
- `resolve_nf_by_a(a,m?,z?,x?,profile)`：`A+m+z` / `A+m` / `A+z` / 只给 `A` 四种给法；
  `A` 为主参数（输入 x 与之不符时按 A 取公式解并明文提示）；表外按主系列 x=0.8 推导
  `N = A/m − 2`（A+m）或 `m = A/(N+2x+0.4)`（A+z），来源 `D_bOrigin::NfTable / Formula / Derived / Adjusted`。
- `resolve_spline`：`SplineStd::NF` 复用同一入口；不给 A 时由 `m/z/x` 正算
  `A=m(N+2x+0.4)`（`D_bOrigin::ComputedA`，x 缺省 0.8）。GB/ANSI/M/DP 给 A/d_B 仍报错。
- 预设：`NF_PRESETS = {NF平齿根（ha*=0.2, hf*=1.0, rho*=0.3），NF圆齿根（…, hf*=1.147, rho*=0.528）}`；
  代号 `NFP` / `NFR`；`NF` / `NFE22141` / `NF E22-141` 取默认平齿根。
- 端视/侧视/剖视/内花键/CHECK 均复用既有共用通路（NF 只是体系分支，没有另开视图代码）；
  内花键与内齿轮同口径只出 剖视图 + 端视图，无侧视图（侧视图/剖视图由齿轮侧 `GearView` 过滤）。
